# 실제 응답 샘플 보관

실제 KMA 단기예보/ASOS 응답을 여기에 넣으면 후속 작업에서 매핑합니다.
웹 시연은 이 샘플을 자동으로 읽거나 수집하지 않습니다.
사용자가 scripts/fetch_asos_samples.py를 직접 실행할 때만 프로젝트 .env의 KMA_API_KEY를 읽어 ASOS를 수집합니다.
에이전트는 프로젝트 .env를 직접 열거나 출력하지 않으며 실제 수집 명령을 실행하지 않습니다.

- 인증키와 개인정보를 제거한 원본 JSON/XML/CSV 및 사용한 공식 문서
- 서비스명, 인증키를 제거한 요청 정보, 조회 날짜와 시각(KST), 지점/격자
- 정상 응답, 빈 응답, 오류 응답, 누락값 사례, 여러 페이지 사례
- ASOS 일사량 단위 및 누적 기간, 제공 지점 안내

이 폴더의 샘플은 기본적으로 git에서 제외됩니다. 인증 정보가 있는 요청 URL은 넣지 마세요.

ASOS 다운로드 결과는 지점·기간별 JSON 한 파일에 모든 페이지를 합칩니다.
records에는 가이드 응답 필드만 보존하며, 요청 URL·인증키·원문 오류는 저장하지 않습니다.
icsr는 MJ/m2 원문 값이며 W/m²로 변환하지 않습니다. 시간대·누적 구간은 가이드에서 확인되지 않았습니다.
최고기온/최저습도, 미수신 시간 및 일사 결측 집계를 daily_summary에 함께 저장합니다.
일사 결측 시간은 누락·빈 값·비수치 응답 및 미수신 시간을 포함하고,0.0은 존재하는 값입니다.
이 파일은 실제 ASOS 어댑터의 후속 검증용이며 현재 mock 웹 앱에 바로 반영되는 형식은 아닙니다.
