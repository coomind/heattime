# HeatTime · 7분 발표 문구와 발표자 대본

슬라이드 파일을 생성하지 않는다. 이 문서를 발표 제작의 원고로 사용한다.
시연은 **기상청 관측 자료(수원119·2026-07-10)를 입력으로 한 가상 대회**이다. 관측 시연 스냅샷은 사전 계산 결과다. 외부 배포·현장 WBGT·현장 사용 검증은 보류 상태다.
고정 스냅샷의 수치와 일반 재현의 실행 수치를 구분한다. 아래 결과는 실제 관측 입력의 가상 대회 결과이며 합성 테스트 수치를 섞지 않는다.
7월10일 시연 수치는 슬라이드3~6에, 62일 분석과 가정은 슬라이드7B에만 배치한다. 민감도 표와 최고 추정값 설명은 별도 질의응답 부록 화면으로 사용한다.

## 1 · 문제: 폭염 판단을 경기 운영으로 연결하기

**화면 문구**

- HeatTime · 생활체육·유소년 축구대회 폭염 의사결정 보조
- 진행·휴식·시간 이동·연기 판단에 필요한 근거를 한 화면에
- 일정 변경 이후 팀 안내와 운영 기록까지 연결

**발표자 대본**

한 경기를 더 시원한 시간으로 옮기면 같은 팀의 휴식, 다음 라운드 시작, 다른 구장 사용과 일몰까지
다시 확인해야 합니다. 변경 내용을 팀에 전달하고 판단 근거도 남겨야 합니다.
HeatTime은 열 위험과 이 대진 제약을 함께 검사해 일정 대안을 제시하고,
운영자 승인부터 안내·기록까지 연결하는 의사결정 보조 서비스입니다.
현재는 가상 대회로 기능을 검증했습니다. 실제 현장 인터뷰나 도입 실적은 아직 없습니다.

## 2 · 왜 지금: 공개 기준을 실행 가능한 일정으로

**화면 문구**

- WBGT는 기온 외 습도·바람·일사 영향을 함께 고려하는 지표
- FIFPRO 권고: WBGT 26℃ **초과** 냉각 조치, 28℃ **초과** 지연·연기
- 국내 유소년 적용은 전문가 검토 필요
- 대진표 자동화·경기 순서 최적화는 기존 제품에도 공개된 기능
- 차별화 가설: 열 위험 판정 + 휴식·선행 대진·일몰 제약 → 일정 대안·연기 사유·승인 근거

**발표자 대본**

FIFPRO는 WBGT 26도를 넘으면 쿨링브레이크, 28도를 넘으면 경기 지연이나 연기를 권고합니다.
프로 축구 지침이므로 국내 유소년 적용은 자문이 필요합니다.
대진표 자동화와 경기 순서 최적화는 이미 제품에 공개된 기능입니다.
HeatTime은 열 위험 판정과 휴식·선행 대진·일몰 제약을 연결한 일정 대안과 판단 근거를 보여줍니다.
경쟁 제품 전체를 시험하지 않아 국내 최초나 독점 기능을 주장하지 않습니다.

근거: [FIFPRO 지침 p.2](https://media.fifpro.org/media/ltio1czh/heat-guidelines_en-1.pdf),
[일본 환경성 스포츠 WBGT 지침](https://www.wbgt.env.go.jp/en/sp/wbgt.php),
[스파인더 공식 FAQ](https://www.sfinder.co.kr/faq/list), [스포츠프리즘 공식 소개](https://www.sportsprism.net/about/company-intro).
확인 범위와 해석은 [공모전 비교](../submission/competition-fit.md)에 기록했다.

- 관측 스냅샷: 사전 계산 · 오프라인 시연 · 실제 운영 판단 기록 아님

## 4 · 히트맵과 경기 상세: 값보다 근거를 함께

**화면 문구**

- 구장×시간 위험 단계: 색 + 아이콘 + 텍스트
- WBGT **추정** 중앙값과 low~high 범위
- 7월10일 중앙 최고32.043℃ · 추정 범위30.543~33.543℃
- 유소년은 상단값으로 판정하는 설계 가정
- 정책 출처·입력 기상·계산 가정 확인

**발표자 대본**

세 구장의 시간별 위험 단계와 경기 위치가 보입니다. 색만 보지 않아도 단계 이름과 아이콘으로
읽을 수 있습니다. 위험한 경기를 누르면 시간별 추정값과 범위가 함께 표시됩니다.
유소년은 범위 상단값으로 판단하도록 설계했습니다. 이 범위는 현장 검증된 통계 신뢰구간이
아니며 설정 가정입니다. 아래에서 정책 출처와 기온·습도·풍속, 계산 방법을 확인할 수 있습니다.

## 5 · 재편성과 운영자 승인: 연기는 최후 수단

**화면 문구**

- 중지 구간 배정 금지 · 구장 중복 금지 · 팀 휴식 · 선행 경기 · 운영 시간/일몰
- 먼저 연기 수 최소화, 그다음 열 노출·이동 비용
- 열 노출은 두 일정의 **공통 경기**끼리 비교 · 연기 수는 별도
- 자동 제안 요약: 15배정 / 0연기 / 원래 중지10경기 제안 배정 · 공통 점수29.36% 감소
- 운영자 사유 입력 → 승인 / 직접 수정 / 거절

**발표자 대본**

재편성을 실행합니다. 중지 시간대를 피하면서 구장 중복, 같은 팀 휴식, 선행 경기, 운영 시간과
조명 없는 구장의 일몰을 검사합니다. 연기를 먼저 줄이고 그다음 열 노출과 이동 비용을 줄입니다.
화면의 열 노출 비교는 두 일정에 공통으로 들어간 경기만 비교합니다. 연기 수와 사유는 따로 보입니다.
이 고정 결과는 원래 중지 단계였던10경기를 이동해15경기 모두 배정했고 연기는0경기입니다.
공통15경기 열 노출 점수는6114에서4319로 줄었습니다. 다른 날짜에 배정되지 않는 경기는 그대로 연기합니다.
운영자가 이유를 적고 승인합니다. 시간 제한 내 결과는 최적성 증명이 미확정일 수도 있으며 화면에 표시합니다.

**발표자 메모**: 62일을 같은 정책·기본 운영값으로 분석해 연기 수 최소 → 원래 중지 경기의 배정 수 최대 → 공통 열 노출 감소 순으로 후보를 골랐다.
후보는7월10일,7월18일,7월6일. 점수 감소는 건강 효과나 사고 감소율이 아니다. 일반 재현에서는 실제 화면 수치를 읽는다.

## 6 · 팀 안내와 근거 기록

**화면 문구**

- 팀별 변경 일정·쿨링브레이크·수분 보충 안내
- 연기 경기에도 사유와 후속 안내 · 실제 발송 없이 모의 로그
- PDF/CSV/JSON: 입력·추정·범위·정책·운영 조치·사유
- 본 자료는 의사결정 보조용 추정값

**발표자 대본**

승인 이후 팀별 모의 알림이 기록됩니다. 변경 일정과 쿨링브레이크 시각, 수분 보충 안내를 확인합니다.
연기된 경기는 사유를 안내합니다. 토너먼트 진출 팀이 아직 정해지지 않았으면 진출 가능 팀 대상이라는
표시를 붙입니다. 실제 문자나 카카오 메시지를 보내지는 않습니다.
운영 기록에서 PDF를 내려받겠습니다. 입력과 추정 범위, 정책 출처, 운영자 조치와 이유가 보존됩니다.
참가팀은 읽기 전용 일정 링크로 변경 내용을 확인할 수 있습니다.

## 7A · 기술: 추정 오차를 드러내고 제약을 검사

**화면 문구**

- 기상 입력 → pvlib 일사 추정 → Liljegren WBGT → 정책 판정
- 관측 일사량이 있으면 우선 사용 · 현장 WBGT 입력 이후 보정
- 불확실성 기본 ±1.5℃, 구장 기본 +2.5℃ · 검토가 필요한 가정
- OR-Tools CP-SAT, 최대10초 · 제약 검사 · 탐욕 폴백
- 일사 비교 부기: 관측927시간·결측561시간 제외·MAE62.67W/m²·편향+6.74W/m²·최대 오차460.07W/m². 현장 WBGT 정확도 검증 아님

**발표자 대본**

관측 일사를 우선 쓰고, 결측은 추정합니다. 공개 Liljegren 모델로 WBGT와 범위를 표시합니다.
가정을 기록하고, 최대10초의 일정 탐색 뒤 제약을 검사합니다. 현장 정확도 검증은 다음 단계입니다.

**발표자 메모**: 일사 비교 수치는 화면 부기로 남기고 읽지 않는다. 방법 설명을20초로 줄여 다음 분석 설명40초를 확보했다.

**화면 문구**

- 수원 관측 자료로 재현한 가상 12팀 대회에서는 62일 중 46일에, 일정을 재배치해도 15경기 전부를 같은 날 배정할 수 없었습니다.

- 관측 입력 기반 WBGT 추정·가상 대회 분석 · 실제 대회 일반의 개최 불가 일수가 아님

**발표자 대본**

수원 관측 자료로 재현한 가상 12팀 대회에서는 62일 중 46일에, 일정을 재배치해도 15경기 전부를 같은 날 배정할 수 없었습니다.

## 8 · 사업화: 검증할 고객과 수익 가설

**화면 문구**

- 첫 사용자 가설: 여름 유소년 축구대회 시간표 변경을 맡는 운영 실무자
- 구매자 가설: 반복 대회를 주최하는 체육회·종목 협회의 예산 담당자
- 도입 가설: 기존 대진 CSV → 과거 관측 비교 → 제안 확인·승인 → 기록
- 연간 구독 가설: 반복 대회 관리·판단 기록·팀 안내, 가격·지불 의사 미검증
- 다음 검증: 실제 운영자 인터뷰 → 준비/변경/기록 시간 비교 → 구매 결정 확인

**발표자 대본**

첫 사용자는 여름 유소년 축구대회에서 시간표를 바꾸는 운영 실무자로 가정합니다.
구매자는 반복 대회를 주최하는 체육회·협회의 예산 담당자입니다.
기존 대진 CSV를 가져와 과거 관측으로 비교하는 흐름부터 검증합니다.
준비와 변경, 기록에 드는 시간을 현재 방식과 비교하고 실제 구매 결정을 확인하겠습니다.
반복 대회 관리의 연간 구독은 가설이며 유료 고객·검증된 가격·시장 규모는 없습니다.
미세먼지·한파·낙뢰는 로드맵이고 현재 기능은 폭염 운영입니다.

- 최종 운영 판단은 주최자 · 의사결정 보조

**발표자 대본**

보정 +2.5℃는 해외 연구 기반 설계 가정으로, 국내 구장 검증과 전문가 검토가 필요합니다.
공간 차이는 미측정이며 현장 WBGT 대조·인터뷰·전문가 자문은 아직 하지 않았습니다.
영상 기반 개인 부하는 아마추어 영상 품질을 통과하지 못한 연구 단계이며 제품 기능으로 제시하지 않습니다.
HeatTime은 최종 판단을 맡는 주최자에게 근거와 실행 가능한 일정안을 제공하겠습니다.
