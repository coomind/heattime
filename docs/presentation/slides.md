# HeatTime · 7분 발표 문구와 발표자 대본

슬라이드 파일을 생성하지 않는다. 이 문서를 발표 제작의 원고로 사용한다.
시연은 **가상 예시 · mock 합성 기상 재현**이다. 실제 관측 재현·외부 배포·현장 사용 검증은 보류 상태다.
아래 배정 수는 고정 문구로 쓰지 말고 실행 화면을 그대로 읽는다. 기본 mock과 P3 테스트 시나리오는 다르다.

## 1 · 문제: 폭염 판단을 경기 운영으로 연결하기

**화면 문구**

- HeatTime · 생활체육·유소년 축구대회 폭염 의사결정 보조
- 진행·휴식·시간 이동·연기 판단에 필요한 근거를 한 화면에
- 일정 변경 이후 팀 안내와 운영 기록까지 연결

**발표자 대본**

여름 대회를 준비하면 날씨를 확인하는 것에서 판단이 끝나지 않습니다. 어떤 경기를 이동할지,
팀의 휴식은 확보되는지, 변경 내용을 어떻게 전달할지까지 결정해야 합니다.
HeatTime은 구장과 대진을 바탕으로 위험 구간을 보여주고, 제약을 지키는 일정안을 제시하며,
운영자가 선택한 이유를 기록하는 의사결정 보조 서비스입니다.
현재는 가상 대회로 기능을 검증했습니다. 실제 현장 인터뷰나 도입 실적은 아직 없습니다.

## 2 · 왜 지금: 공개 기준을 실행 가능한 일정으로

**화면 문구**

- WBGT는 기온 외 습도·바람·일사 영향을 함께 고려하는 지표
- FIFPRO 권고: WBGT 26℃ **초과** 냉각 조치, 28℃ **초과** 지연·연기
- 국내 유소년 적용은 전문가 검토 필요
- 차별화 가설: 대진·휴식·선행 경기·팀 안내·기록을 함께 다루는 운영 흐름

**발표자 대본**

공개 스포츠 지침은 더운 날씨에서 활동 조정을 권고합니다. FIFPRO는 WBGT 26도를 넘으면
쿨링브레이크, 28도를 넘으면 경기 지연이나 연기를 권고합니다. 이는 프로 축구 지침이며
국내 유소년 대회에 그대로 적용할 수 있는지는 자문이 필요합니다.
저희는 이 기준을 화면에 표시하고 실제 대진 제약과 연결했습니다.
국내 경쟁 제품의 기능 전체를 조사한 것은 아니므로 국내 최초나 경쟁사 기능 부재를 주장하지 않습니다.

근거: [FIFPRO 지침 p.2](https://media.fifpro.org/media/ltio1czh/heat-guidelines_en-1.pdf),
[일본 환경성 스포츠 WBGT 지침](https://www.wbgt.env.go.jp/en/sp/wbgt.php).

## 3 · 시연 시작: 그날 이 대회였다면

**화면 문구**

- 수원 지역 가상 구장 3곳 · U12 가상 12팀 · 15경기
- 2026-08-01은 시연 날짜, 기상은 합성 예시
- 실제 ASOS 응답 확보 후 실제 관측 재현으로 전환 예정

**발표자 대본**

재현 모드에서 수원과 가상 유소년 대회를 선택합니다. 지금 날짜는 2026년 8월 1일이지만
기상청 실측 자료가 아니라 합성 데이터입니다. API 키 없이도 시연할 수 있습니다.
재현 시뮬레이션을 실행하겠습니다.

## 4 · 히트맵과 경기 상세: 값보다 근거를 함께

**화면 문구**

- 구장×시간 위험 단계: 색 + 아이콘 + 텍스트
- WBGT **추정** 중앙값과 low~high 범위
- 유소년은 상단값으로 판정하는 설계 가정
- 정책 출처·입력 기상·계산 가정 확인

**발표자 대본**

세 구장의 시간별 위험 단계와 경기 위치가 보입니다. 색만 보지 않아도 단계 이름과 아이콘으로
읽을 수 있습니다. 위험한 경기를 누르면 시간별 추정값과 범위가 함께 표시됩니다.
유소년은 범위 상단값으로 판단하도록 설계했습니다. 이 범위는 현장 검증된 통계 신뢰구간이
아니며 설정 가정입니다. 아래에서 정책 출처와 기온·습도·풍속, 계산 방법을 확인할 수 있습니다.

## 5 · 재편성과 운영자 승인: 연기는 최후 수단

**화면 문구**

- 중지 구간 배정 금지 · 구장 중복 금지 · 팀 휴식 · 선행 경기 · 운영 시간/일몰
- 먼저 연기 수 최소화, 그다음 열 노출·이동 비용
- 열 노출은 두 일정의 **공통 경기**끼리 비교 · 연기 수는 별도
- 운영자 사유 입력 → 승인 / 직접 수정 / 거절

**발표자 대본**

재편성을 실행합니다. 중지 시간대를 피하면서 구장 중복, 같은 팀 휴식, 선행 경기, 운영 시간과
조명 없는 구장의 일몰을 검사합니다. 연기를 먼저 줄이고 그다음 열 노출과 이동 비용을 줄입니다.
화면의 열 노출 비교는 두 일정에 공통으로 들어간 경기만 비교합니다. 연기 수와 사유는 따로 보입니다.
현재 합성 날씨는 매우 더워서 많은 경기가 연기될 수 있습니다. 억지로 모든 경기를 배정하지 않습니다.
운영자가 이유를 적고 승인합니다. 시간 제한 내 결과는 최적성 증명이 미확정일 수도 있으며 화면에 표시합니다.

**발표자 메모**: 무난한 테스트는15경기 전부 배정. 별도 무더위 테스트는14경기 배정/결승1경기 연기,
그 결승을 강제로 배정하면 INFEASIBLE. 공통14경기 점수6080→2856.
이 수치는 통제된 테스트 결과이며 현재 기본 mock 화면 결과나 건강 효과로 발표하지 않는다.

## 6 · 팀 안내와 근거 기록

**화면 문구**

- 팀별 변경 일정·쿨링브레이크·수분 보충 안내
- 연기 경기에도 사유와 후속 안내 · 실제 발송 없이 모의 로그
- PDF/CSV/JSON: 입력·추정·범위·정책·운영 조치·사유
- 본 자료는 의사결정 보조용 추정값

**발표자 대본**

승인 이후 팀별 모의 알림이 기록됩니다. 변경 일정과 쿨링브레이크 시각, 수분 보충 안내를 확인합니다.
연기된 경기는 사유를 안내합니다. 토너먼트 진출 팀이 아직 정해지지 않았으면 진출 가능 팀 대상이라는
표시를 붙입니다. 실제 문자나 카카오 메시지를 보내지는 않습니다.
운영 기록에서 PDF를 내려받겠습니다. 입력과 추정 범위, 정책 출처, 운영자 조치와 이유가 보존됩니다.
참가팀은 읽기 전용 일정 링크로 변경 내용을 확인할 수 있습니다.

## 7 · 기술: 추정 오차를 드러내고 제약을 검사

**화면 문구**

- 기상 입력 → pvlib 일사 추정 → Liljegren WBGT → 정책 판정
- 관측 일사량이 있으면 우선 사용 · 현장 WBGT 입력 이후 보정
- 불확실성 기본 ±1.5℃, 구장 기본 +2.5℃ · 검토가 필요한 가정
- OR-Tools CP-SAT, 최대10초 · 제약 검사 · 탐욕 폴백

**발표자 대본**

일사량이 없으면 태양 위치와 맑은하늘 일사량에 운량과 강수 보정을 적용합니다.
WBGT는 라이선스를 확인한 공개 Liljegren 구현을 사용했습니다. 계산이 실패하면 간이 추정으로
표시합니다. 기압과 고도, 풍속 높이, 구장 보정 등의 가정도 기록합니다.
현장 WBGT를 입력하면 이후 추정을 보정하고 기존 범위를 임의로 좁히지 않습니다.
최적화는 최대10초 실행하며 제약을 별도로 검사합니다.
일사 비교 그래프와 오차 지표는 생성되지만 현재는 합성 데이터 검증이므로 현장 정확도라고 제시하지 않습니다.

## 8 · 사업화: 검증할 고객과 수익 가설

**화면 문구**

- 고객 가설: 시·군 체육회, 종목 협회, 학교 운동부
- 연간 구독 가설: 대회 관리·판단 기록·팀 안내
- 측정기 업체 연동 협력 가능성
- 다음 검증: 운영자 인터뷰 → 현장 시범 → 지불 의사 확인

**발표자 대본**

고객은 여러 대회를 반복 운영하는 체육회, 협회, 학교 운동부로 가정하고 있습니다.
연간 구독으로 대회와 기록을 관리하고 측정기 업체와 연동하는 모델을 검토합니다.
현재 유료 고객이나 검증된 가격, 시장 규모는 없습니다. 먼저 운영자가 어떤 판단과 기록에 시간을 쓰는지
인터뷰하고 가상 시연에서 현장 시범으로 넘어가겠습니다.
미세먼지와 한파, 낙뢰로 확장하는 계획은 있지만 현재 구현 기능은 폭염 경기 운영입니다.

## 9 · 한계와 로드맵

**화면 문구**

- WBGT 추정 오차: 실제 ASOS·구장 실측으로 검증 예정
- 연령 보정·현장 계수·운영시간: 전문가 자문 필요
- 실제 기상 연동·외부 배포·현장 도입 검증: 미완료
- 영상 기반 개인 부하: **연구 단계 · 아마추어 영상 품질 미통과**
- 최종 운영 판단은 주최자 · 의사결정 보조

**발표자 대본**

현재 가장 큰 한계는 실제 관측과 현장 측정으로 추정 오차를 검증하지 못했다는 점입니다.
실제 응답을 확보하고 관측 일사 비교와 구장 WBGT 대조를 진행하겠습니다.
연령 보정과 경기 운영값은 전문가 자문을 받겠습니다. 외부 배포와 현장 도입도 아직 검증 전입니다.
영상 기반 개인 부하는 아마추어 영상 품질을 통과하지 못한 연구 단계이며 제품 기능으로 제시하지 않습니다.
HeatTime은 최종 판단을 맡는 주최자에게 근거와 실행 가능한 일정안을 제공하겠습니다.
