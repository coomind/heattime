# 시연 영상 촬영·리허설 체크리스트

이 단계에서는 영상이나 슬라이드 파일을 만들지 않았다. 사용자가 직접 촬영할 때 아래를 확인한다.

## 촬영 전

- [ ] 1920×1080, 30fps 권장. 브라우저 확대100~125%에서 한글과 WBGT 범위가 읽히는지 확인
- [ ] 화면과 마이크를10초 시험 촬영해 글자·클릭·음량 확인, 개인정보/키가 보이는 다른 창 닫기
- [ ] README대로 서버·정적 화면 실행. 초기 재현 모드에서 새 세션 생성 준비
- [ ] 기상청 관측 자료(수원119·2026-07-10)·가상12팀·3구장·관측 시연 스냅샷 라벨 확인
- [ ] 관측 스냅샷 저장 완료 후 새로고침, 연결 없이 전체 흐름 진행 확인
- [ ] 실제 API 키 없이 실행. .env를 화면에 열거나 녹화하지 않기
- [ ] 실제 배포 후에는 외부 링크를 시크릿 창·휴대폰에서 별도 검증
- [ ] PDF 첫/경기 페이지와 모바일 대체 화면을 미리 준비

## 촬영 순서·확대 지점

- [ ] demo-script.md의1:20–4:20 순서대로 진행. 클릭 후 결과가 나온 것을 확인하고 이동
- [ ] 히트맵: 색·아이콘·단계 텍스트와 가상 라벨 확대
- [ ] 경기 상세: WBGT 추정 low~high 음영, 정책 출처, 연령 자문 문구 확대
- [ ] 비교: 공통 경기 점수와 별도 연기 수를 함께 보이기. 수치 단위는 점수이며 건강 효과가 아님
- [ ] 제안 승인: 스냅샷의 고정 가상 사유와 기록 완료 상태 촬영(일반 관측 재현은 사유 직접 입력)
- [ ] 알림: 팀명·모의 수신함·변경 일정 또는 연기 사유·수분 안내 확대
- [ ] PDF: 기상청 수원119·관측 날짜·일사 시간평균·수집 시각·추정 범위·정책·조치·사유·하단 고지 확인
- [ ] 읽기 전용 링크: 승인 버튼이 없는 참가팀 화면 확인

## 실패시 대체

- [ ] 서버/외부 링크 장애에 대비해 저장된 관측 스냅샷과 사용자가 직접 녹화한 관측 입력 시연 영상 준비
- [ ] PDF 열기가 늦으면 사전에 내려받은 기록으로 전환, 녹화 시점의 기록임을 안내
- [ ] 관측 스냅샷15배정/0연기·6114→4319와 원래 중지10경기 확인. 다른 날짜·과거 합성 테스트 수치와 섞지 않기
- [ ] 승인 중복 오류는 새 재현 실행으로 해결. 제약 위반 수정안이 차단되는 것은 정상 동작
- [ ] 영상 종료 후 전체7분, 시연3분으로 리허설. 불필요한 대기·긴 표 탐색 줄이기

## 제출 전

- [ ] 외부 서비스 주소와 영상 링크가 로그인 없이 열리는지 확인 (현재 둘 다 미제공)
- [ ] 모든 가상 데이터 라벨, 모든 추정값 범위, 과장 표현 없는지 확인
- [ ] 발표 출처 슬라이드와 공개 구현·글꼴 라이선스 유지
- [ ] 공모요강의 형식·접수 마감·필수 서류를 공식 페이지에서 재확인
- [ ] PDF/CSV/JSON 및 녹화 원본을 별도 보관. 무료 임시 저장소 재시작시 기록 소실에 대비
