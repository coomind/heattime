# 슬라이드·시연 영상용 화면 캡처 목록

이 문서는 사용자가 캡처·녹화할 화면과 순서를 정하는 계획이다. 발표용 슬라이드 파일, 캡처 이미지, 영상은 만들지 않았다. 기존 브라우저 테스트의 검증용 화면·PDF 출력은 발표 제작 산출물과 별도다.
7분 본 발표와 3분 시연의 시간은 아래처럼 고정한다. 질의응답 부록은 본 발표 시간에 포함하지 않는다.

**7B 화면 문장**: 수원 관측 자료로 재현한 가상 12팀 대회에서는 62일 중 46일에, 일정을 재배치해도 15경기 전부를 같은 날 배정할 수 없었습니다.

**같은 화면의 가정**: 경기장 보정 +2.5℃, 유소년 추정 상단값 판정, 동일 관측소 1곳 공유, 이 가상 대회의 대진·휴식·운영시간·일몰 제약.

**구분**: 0경기 배정일은3일(8월 4·5·6일). 나머지43일은 일부 경기 배정 가능. 실제 유소년 대회 일반의 개최 불가 일수가 아니다.

## 관측 시연 영상 · 총180초

README 절차로 실행한 로컬 서버에서 `http://127.0.0.1:8000/#snapshot-observed`를 사용한다. 관측 스냅샷 저장 완료를 확인하고 새로고침한다. 녹화 전 로딩을 마친 뒤 시작하고, 결과가 보이면 다음 장면으로 이동한다. 로그인·실제 발송·API 수집을 하지 않는다.
정지 캡처를 슬라이드에 쓸 때도 아래와 같은 순서와 표시 시간을 따른다. 클릭 동작은 영상에서 보여준다.

영상에서 쓸 7월10일 수치는15배정/0연기, 공통 경기6114→4319, 추정 중앙 최고32.043℃(추정 범위30.543~33.543℃)다. 전체기간 최고값이나 민감도 표를 같은 화면에 넣지 않는다. 영상 전 구간 또는 각 정지 캡처에 관측 입력·가상 대회·WBGT 추정·사전 계산을 표시한다. 열 노출 점수 감소를 건강 효과로 설명하지 않는다.
PDF가 늦으면 기존 `data/output/real/observed-snapshot.pdf`의 같은 관측 기록으로 전환한다. 승인 중복은 새 재현으로 초기화한다. 촬영 절차는 [시연 대본](demo-script.md), 확인 목록은 [리허설 체크리스트](recording-checklist.md)를 따른다.

## 질의응답용 별도 부록 화면 · 본 발표 외

| 순서 | 질문 | 캡처·편집 화면 | 표시 시간 | 분리 규칙 |
|---|---|---|---:|---|
| A | 보정값 때문에 달라지나? | qa.md의 민감도3행 표: 기본46일/보정0℃30일/보정0℃+중앙값15일 | 30초 | 같은 가상 대회의 동일일15경기 배정 실패일; 기본값 변경 근거 아님 |
| B | 최고값이 실제로 나오나? | qa.md의 최고값 설명: 관측 WBGT가 아니라 관측 입력 기반 추정35.56℃에 경기장 보정 +2.5℃를 더한 중앙값38.062℃, 추정 범위36.562~39.562℃ | 30초 | 8월6일16시·가상 구장B·모델의 약풍/복사 영향·현장 대조 미수행 |
| C | 관측소 하나가 대표하나? | 관측소 한 곳→가상3구장 공유 도식과 미측정 설명 | 30초 | 공간 차이 미측정·가상±1℃는 관측 오차 범위/신뢰구간 아님 |

A/B/C는 서로 다른 화면이다. 시연 결과 수치를 겹쳐 넣지 않는다. 보정값은 일반 재현의 설정에서 조정할 수 있음을 설명하되 촬영 중 기본 설정을 저장·변경하지 않는다. 중앙값 판정 비교는 분석용이며 앱의 유소년 정책 변경 기능으로 소개하지 않는다.

[글자 수 시간 점검](timing-check.md)과 실제 소리 내어 읽는 리허설을 함께 확인한다. 화면 클릭·PDF 확대·질의응답의 실제 시간은 사용자가 촬영 전에 확인한다.
