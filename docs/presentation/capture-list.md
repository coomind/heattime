# 슬라이드·시연 영상용 화면 캡처 목록

이 문서는 사용자가 캡처·녹화할 화면과 순서를 정하는 계획이다. 발표용 슬라이드 파일, 캡처 이미지, 영상은 만들지 않았다. 기존 브라우저 테스트의 검증용 화면·PDF 출력은 발표 제작 산출물과 별도다.
7분 본 발표와 3분 시연의 시간은 아래처럼 고정한다. 질의응답 부록은 본 발표 시간에 포함하지 않는다. 2026-10-11 재계산: 일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정 후 전 수치 재생성.

본 발표 외 과거 분석 부록은 앱에 새 분석 화면을 추가하는 작업이 아니다. 기존 보고서를 근거로 발표 제작 때 구성할 화면이다. 8월10일 시연 화면과 수치 자막을 지운 뒤 부록으로 전환한다. 부록은 본 발표 외 질의응답 때만 사용한다.

**본 발표 외 과거 분석 부록 문장**: 수원 관측 자료로 재현한 가상 12팀 대회에서는 62일 중 47일에, 일정을 재배치해도 15경기 전부를 같은 날 배정할 수 없었습니다.

**같은 화면의 가정**: 경기장 보정 +2.5℃, 유소년 추정 상단값 판정, 동일 관측소 1곳 공유, 이 가상 대회의 대진·휴식·운영시간·일몰 제약.

**구분**: 0경기 배정일은10일(7월11·12·13·31일, 8월1·3·4·5·6·7일). 나머지37일은 일부 경기 배정 가능. 실제 유소년 대회 일반의 개최 불가 일수가 아니다.

대표일: 시간자료 최고기온31.6℃·운영시간 습도44~67%. 일 최고기온31℃ 이상인 날 중 연기 수 최소→원래 중지였다가 배정된 경기 수 최대→공통 점수 감소→날짜 순의 선택 규칙과 5회 반복 확인을 자막/원고로 밝힌다. 최고기온33℃ 이상인 날은 모두8경기 이상 연기되어 그 조건에서는 시연일 기준을 만족하는 날이 없었다는 점도 밝힌다. 평균적 운영 효과를 대표하지 않는다. 8월4일0배정 화면은 본 발표 외 부록에 별도10초로 보여주며180초 본 영상에 덧붙이지 않는다.

PDF가 늦으면 기존 `data/output/real/observed-snapshot.pdf`의 같은 관측 기록으로 전환한다. 승인 중복은 새 재현으로 초기화한다. 촬영 절차는 [시연 대본](demo-script.md), 확인 목록은 [리허설 체크리스트](recording-checklist.md)를 따른다.

A/B/C는 서로 다른 화면이다. 시연 결과 수치를 겹쳐 넣지 않는다. 보정값은 일반 재현의 설정에서 조정할 수 있음을 설명하되 촬영 중 기본 설정을 저장·변경하지 않는다. 중앙값 판정 비교는 분석용이며 앱의 유소년 정책 변경 기능으로 소개하지 않는다.

[글자 수 시간 점검](timing-check.md)과 실제 소리 내어 읽는 리허설을 함께 확인한다. 화면 클릭·PDF 확대·질의응답의 실제 시간은 사용자가 촬영 전에 확인한다.
