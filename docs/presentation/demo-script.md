## 대체 흐름

- 재편성은 최대10초다. 오래 걸리면 현재 시간 제한/최적성 상태를 읽고 결과를 기다린다.
- 합성 프로필이 매우 더워 대부분 연기되어도 그대로 보여준다. 승인/기록 흐름은 진행된다.
- 같은 세션은 다시 승인할 수 없다. 재현 모드에서 새 시뮬레이션을 실행한다.
- PDF가 자동으로 내려받아지면 다운로드 목록에서 열거나 준비한 PDF로 전환한다.
- 서버·외부 링크가 실패하면 직접 녹화한 영상으로 전환하고, 영상은 녹화일의 합성 시연임을 말한다.
- 아직 영상은 제작하지 않았다. data/output/p5/의 화면·PDF는 리허설 참고 자료이며 대체 영상이 아니다.
- 실제 ASOS 자료가 준비되면 날짜·지점·출처를 다시 검증한 별도 시연을 녹화한다.

## 혼동 방지

P3 통제된 무더위 테스트의14배정/1연기를 기본 mock 화면에서 기대하지 않는다.
화면에 나온 실제 배정/연기 수만 읽고, 열 노출 감소를 사고 감소율로 표현하지 않는다.
부득이한 연기는 운영시간·휴식·선행 경기·중지 구간이 함께 제한하는 결과다.
