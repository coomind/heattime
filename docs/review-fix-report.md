## 복제와 ZIP

mock 두 파일은 이미 Git에 추적되어 있었다. 리뷰ZIP에서 누락한 결함을 수정했다. Docker 로컬 COPY 경로는 모두 추적/존재 검사를 통과했다. 실제 ZIP 전개 후 별도 프로세스 서비스 초기화 회귀 검사와 비밀 파일 미열기 검사를 추가했다.

첫 깨끗한 Windows 복제본에서 README 설치는 성공, Python786개 통과/9개 건너뜀, 프론트 빌드 성공3.57초였다.9개는 기존 민감도 상세 분석이 로컬 출력에만 존재했기 때문이다. 기존 테스트를 건드리지 않고 인증값 없는 과거 가상 회귀 fixture559개(약1.21MB)를 커밋하고 복원 명령을 README에 추가했다.

첫 실제 ZIP 전체 실행은897개 통과/3개 실패였다. .dockerignore 누락 때문에 기존 검사2개, 제공된 ASOS 공식 DOCX 누락 때문에 원문 계약 검사1개가 실패했다. ## 남은 한계와 미실행 항목

보정+2.5℃와 유소년 상단 폭+1.5℃의 국내 현장 타당성은 검증하지 못했다. 판정값 분해와 가정 비교는 그 의존성을 보여주는 기능이며 과민성이 해소됐다는 증거가 아니다. 실제 관측 WBGT·운영자 효용·구매 수요·수상권을 입증한 자료는 없다.

기존 후보 생성과 공통 제약 검사기를 함께 사용하므로 공유 구현 오류 가능성은 남는다. 위험 창은 종료 정각 샘플까지 포함하고, 열 노출 점수는 시간 샘플을 앞으로 유지하며, 관측 일사는 직전1시간 평균이다. 이번 수정에서 이 시간 표현이나 기존 수치를 바꾸지 않았다. 표시 반올림값을 분해하므로 성분은0.001℃ 수준의 표시 정밀도다.

10초는 CP-SAT에 설정한 탐색 제한이다. 준비·단순 대안 생성·검증까지 포함한16팀 전체 호출은 이번93조건 실행에서 중앙12.276초/최대14.595초였고, 솔버 측정 벽시계 최대는10.529초였다. 전체 응답10초를 보장한다고 쓰지 않는다. 정책·시간 제한·운영값을 낮춰 속도를 얻지 않았다.

TestClient의 기존 httpx 사용 중단 예정 경고1건은 남긴다. 호환성·동작 변경 가능성이 있어 이번 범위에서 의존성 교체를 하지 않았다. 실제 배포·로그인·발송·기상 수집·새 실측·인터뷰·영상/PPTX 제작은 하지 않았다.

## 직접 확인할 항목

1. 다른 AI에는 새 리뷰ZIP을 전달한다. 원격 AI는 로컬 경로만으로 파일을 읽을 수 없다.
2. 모형/보정/상단 폭의 분해와 분석용 비교가 설정 변경이나 현장 검증으로 오해되지 않는지 확인한다.
3. 대표일 선정 규칙·후텁지근한 기상·원래 일정의 제약 위반·0배정일을 함께 설명한다.
4. CP-SAT 상태와 선택 방법을 구분하며 FEASIBLE 연기를 불가피했다고 말하지 않는다.
5. 소리 내어7분/3분 발표를 리허설한다. 실제 링크·영상·현장 검증·인터뷰는 이번 작업 범위에서 미실행 상태다.
