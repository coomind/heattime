# 공모요강 비교 및 경쟁력 개선 보고

2026-10-05. 기준 명세·정책·운영값·안전 문구를 유지하며 화면 개선과 출품 원고를 두 작업 단위로 진행했다.

## 판단

**출품 적합성이 높고, 작동하는 시제품·제약 재편성·실제 관측 입력 재현을 근거로 경쟁력을 설명할 수 있다. 그러나 현재 근거로 수상권이라고 단정할 수 없다.** 공개 요강에서 항목별 배점표를 확인하지 못했고 다른 참가작도 알 수 없다. 수상 확률이나 가상의 공식 점수를 만들지 않았다.

명세의 1순위인 안전·시설 관리 기술을 유지하고 대회 운영·관리 기술과 연결했다. 소개서·7분 원고를 갖출 수 있는 시제품이지만 외부 서비스 링크·실제 영상·최종 발표 파일은 준비 완료가 아니다. [공식 요강과 항목별 비교](submission/competition-fit.md).

공식 대회 서비스에는 대진 자동화·기록 관리·진행 순서 최적화가 이미 공개돼 있다. 차별점은 이 기능 자체보다 **폭염 추정·범위 판정과 대진/휴식/일몰 제약을 연결한 대안·연기 사유·승인 근거 기록**으로 설명한다. 일부 공개 페이지 비교이므로 경쟁사 기능 부재·국내 최초·독점 기능을 주장하지 않는다. [스파인더 공식 FAQ](https://www.sfinder.co.kr/faq/list), [스포츠프리즘 공식 소개](https://www.sportsprism.net/about/company-intro).

| 관점 | 개선 전 상태 | 이번에 개선한 것 | 남아 있는 한계 |
|---|---|---|---|
| 시연 결과 전달 | 점수와 연기만으로 결과를 읽어야 함 | 배정/연기/중지 경기 재배정/공통 변화율을 함께 표시 | 가상 재현이며 현장 성과 아님 |
| 차별화 설명 | 운영 흐름이라는 포괄적 설명 | 공개 경쟁 기능과 겹치는 부분을 인정하고 열 위험+제약 결합을 화면으로 입증 | 모든 경쟁 제품을 동일 조건 시험하지 않음 |
| 첫 고객 | 여러 기관을 넓게 제시 | 실제 사용자 역할·구매 담당자·CSV로 시작하는 도입 가설 구체화 | 인터뷰·구매 의사 미확인 |
| 증빙 | 실행 보고가 여러 문서에 분산 | 주장별 원본 연결, 제안서·제출 체크리스트 작성 | 현장 WBGT 정확도·사고 효과 미검증 |
| 검증 계획 | 인터뷰·현장 시범이라는 방향 | 비유도 질문·준비/변경/기록 시간 비교·구매자 확인·반례 기록 계획 | 계획 작성만 완료, 실행하지 않음 |
