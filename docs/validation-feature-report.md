# 운영자·현장 대조 기록 기능 보고

2026-10-06. 사용자 확인: 실제 운영자 사용 기록과 현장 WBGT 기록은 아직 없다. 본 기능의 테스트 자료는 임시 데이터베이스의 가상 시험 자료이며 인터뷰·현장 성과가 아니다.

## 변경 파일과 목적

- `backend/validation.py`, `backend/app.py`: 업무 비교·측정기 대조의 추가 저장, 집계, JSON/CSV 내보내기. 기존 SQLite 자원 저장소를 사용하며 신규 서버·외부 서비스는 없다.
- `frontend/src/ValidationEvidence.jsx`, `App.jsx`: **검증 기록** 메뉴. 실제/가상 구분, 원자료 코드, 수행 시각, 동의·비교 순서·조건·중단, 준비/변경/안내 시간, 부정적 의견·구매 응답을 남긴다. 실제 구장 등록이 가능하도록 구장 폼에 가상 여부를 명시했으며 기본은 여전히 가상이다.
- `tests/test_validation.py`, `frontend/e2e/validation-evidence.spec.js`: 계산·제외·저장·중복·내보내기·화면·스냅샷 회귀 검사 추가. 기존 테스트 삭제·약화 없음.

## 계산과 집계 원칙

업무 비교 총시간은 준비+변경+안내·기록이다. 두 방식 모두 완료·전 단계 시간·동일 조건·하드 제약 통과가 확인된 실제 기록만 집계한다. 동의 없는 실제 기록은 저장하지 않는다. 절감은 현재 방식−HeatTime이며 음수도 보존한다. 다른 사례와 반복 순서를 확인하도록 사례별 결과·진행 순서·참여자 수를 표시한다. 입력자가 선언한 기록이므로 제3자 수행 확인이나 인과 효과 입증은 아니다. 구매 응답은 원문 보존하며 계약·매출로 집계하지 않는다.

현장 대조는 저장된 구장·시각의 추정값을 선택하고 원자료 코드·측정기·프로토콜·높이·위치·교정 근거를 입력한다. 가상 구장, 합성 기상, 시각 불일치, 동일 위치/교정 미확인, 실측 보정된 추정은 실제 대조 집계에서 제외한다. 임의 시간 허용 오차·보간·측정 규격·합격 오차를 만들지 않는다. 동일 시각·구장·기기 자료는 새 재현 ID나 다른 시간대 표현으로도 중복 집계할 수 없다.

MAE·편향은 추정−실측에서 계산한다. 보정 전 값은 저장된 추정 중앙값에서 당시 경기장/표면 오프셋을 뺀 참고값이다. 실측 보정이 있는 자료는 순환 검증을 막기 위해 제외한다. 범위 포함 비율은 표본 내 관찰이며 신뢰구간·건강 효과·안전성 지표가 아니다. 원 추정·입력과 기록 해시는 저장 당시 그대로 보존된다. 이후 구장·세션 변경이 과거 결과를 덮어쓰지 않는다.

예시는 실제 집계에 포함되지 않고 제외 사유를 모두 남긴다. 빈 집계는 0℃ 오차나 0분 절감이 아니라 **미측정**이다. 앱 엔진·정책·운영 기본값과 자동 보정을 변경하지 않았다. 이 기능에 입력한 WBGT는 기존 실측 보정 테이블에 전달하지 않는다.

- Python 신규 검사: **39 passed**, 11.24초. 기존 TestClient 경고 1건 유지.
- 신규 브라우저 검사: **6 passed**, 10.6초(데스크톱/모바일 각 3개). 모의 기록의 실제 집계 제외, 불리한 의견 보존, CSV 다운로드, 모바일 가로 넘침 없음, 스냅샷에서 `/api` 호출 0회, 현장 제외 사유 확인.

- 첫 실행에서 새 테스트 1개가 추가 기록 전용 API의 PUT 상태코드 기대와 달라 실패했다(기존 일반 자원 경로가 404 반환). 테스트를 바꾸지 않고 명시적인 405 응답을 추가했고 전체 신규 검사가 통과했다.
- 전체 회귀 검사 결과는 후속 [종합 보고](award-evidence-report.md)에 기록한다.

## 수용 여부

모의/실제 구분, 준비 포함 및 불리한 결과 보존, 동의·시각·중복 검증, 원 추정 동결, 순환 검증 제외, 미측정 표시, 전체 원자료 내보내기, 스냅샷 읽기 전용: 통과. 실제 운영자 효용·구장 정확도·구매 의사·수상 가능성: **미입증**.

## 내가 확인할 항목

1. 일반 실행 → 검증 기록에서 가상 예시로 입력·다운로드를 확인한다. 실제 자료가 없을 때 실제 구분을 선택하지 않는다.
2. 운영 실무자 3~5명에게 직접 참여 동의를 얻고 [비교 계획](submission/validation-plan.md)에 따라 동일 조건·두 순서로 시간을 기록한다. 연락은 사용자가 수행한다.
3. 실명·연락처·인증키·요청 URL을 입력하지 않는다. 원자료는 코드로 연결하고 공개 제출 전 익명화와 동의 범위를 재확인한다. DB/내보내기 파일을 공개 저장소에 넣지 않는다.
4. 현장 대조 전에 실제 구장 좌표·기기 교정·위치·높이·시각·프로토콜을 전문가와 확정한다. 실제 구장으로 등록하고 가상 대회의 구장과 구분한다. 관측소 한 곳의 자료가 공간 차이를 측정했다는 의미는 아니다.
5. 추가 저장 방식이므로 오기입은 수정으로 감추지 말고 원자료 메모에 남겨 검토한다. 공개용 자료 선정은 제외 사유까지 검토하며 잘못된 기록을 성과로 쓰지 않는다.
