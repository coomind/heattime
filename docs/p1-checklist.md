## 실제 API 연결 (현재 전부 미구현)

- KMA/공공데이터포털 중 사용할 서비스·인증 방식과 승인된 공식 문서
- 실제 엔드포인트, 요청 인자, 예보 발표/발효 시각, 페이지 처리
- 정상/오류/빈 자료 응답 구조 및 각 기상 요소 필드명·단위·결측 코드
- 구장별 ASOS 지점 선정 기준, 자료 제공 기간·지점 목록
- ASOS 일사량 제공 여부, 누적값/평균값/순간값과 단위, W/m² 변환 방법
- 타임존·관측 정시 처리·중복 및 자료 지연 처리
- 인증 정보가 삭제된 data/samples/ 응답과 원문 문서의 일치 확인

내부 WeatherPoint 필드명과 TMP/REH 등의 명세 개념을 실제 응답 필드로 가정하지 않는다.
API 키를 발급받기 전에도 mock 실행과 테스트는 모두 가능하다.
