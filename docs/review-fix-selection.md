# 결과 선택 단계 수정 검증

2026-10-06. 독립 평가에서 지적한16팀 두 열세 사례를 수정했다. 시작 힌트와 최종 후보 비교를 추가했고 정책·운영값·솔버10초는 유지했다. 최종 선택은 같은 제약을 통과한 CP-SAT/단순4종 중 배정 수 최대→기존 비용 최소이며, 동률에는 CP-SAT를 유지한다. 선택 방법·실제 솔버 상태·각 후보 점수를 기록한다.

기존31개 이틀 구간과62개 하루의 입력 지문·날짜를 모두 유지하고 한 번씩 계산했다.16팀 배정은596→608건(단순598건),12팀562건은 유지됐다.7월9~10일16→27,8월16~17일26→27경기다.16팀은12OPTIMAL/19FEASIBLE,12팀은62OPTIMAL이었다. FEASIBLE/폴백 연기 사유는 제한 시간 내 미배정이며 불가능 증명이 아님을 표시한다. 기존 최적성 확인 결과의 사유는 유지한다. 최소 연기 수 증명과 특정 경기의 모든 대안에서의 불가능 증명은 다르다.

새 선택 회귀97개와 기존 규모 검사32개를 실제 실행하여 **129개 통과(136.03초)**. 모든93조건의 현재 입력·전 배정/기존 권고/제약·단순4종·기존12팀 배정 수 비감소·동수 기존 비용 비증가·솔버 상태·미확정 사유를 검사했다. 두 지적 날짜는 실제로 다시 풀어27경기와 하드 제약을 검사했다. 기존 일정 검사10개도 통과(9.93초)했다. 기존 테스트는 삭제/약화하지 않았다.

수용 기준: 모든31구간에서 단순 기준 이상의 배정/제약 충족,62일 배정 수 비감소, 상태/선택 방법/미확정 사유 구분 통과. [새 결과](competition-evidence/review-fix-results.json)는 과거596/598 분석과 별도로 보존한다. 배정 수 우위는 최종 선택 규칙의 성질이며 실제 경기 구제나 독립적 최적화 우위의 증거가 아니다.

직접 확인: 두 수정 사례의 선택 방법과 FEASIBLE 상태를 함께 확인한다. 과거 보고의 수치와 이번 수치를 다른 버전으로 읽고, 모든 경기가 더운 날도 가능하다고 해석하지 않는다. 전체 검사·복제·화면·PDF 결과는 [최종 보고](review-fix-report.md)에 모은다.
