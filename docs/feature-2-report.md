# 기능 2: 입력 근거·현장 보정 이력

> 이전 기준 기록입니다(2026-10-21 이전: 유소년 범위 상단 판정). 현재 수치와 기준은 [2026-10-21 재계산](recalc-2026-10-21.md)을 보세요. 2026-10-11 재계산(일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정) 기록은 [2026-10-11 재계산](recalc-2026-10-11.md)에 있습니다.

2026-10-05. 히트맵의 시간 셀, 원래 경기 상세, 제안/승인 일정의 시간자료에서 입력 근거 패널을 연다. 관측·합성, 기온/습도/풍속 단위, 높이 보정, 기압 가정, 관측 일사 원값과 시간평균 변환, 일사 추정·범위·결측, 구장 보정, 산정 방법/폴백, 입력 지문을 한곳에 표시한다. 기존 추정 범위를 검증된 신뢰구간으로 설명하지 않는다.

수동 입력 이력을 재현 시점에 보존하고, 기존 엔진의 자료 구분·측정 시각·참고 자료 조건에 따라 적용/미적용/후속 입력 대체를 표시한다. 승인 시점에는 이력도 고정한다. 원래 스냅샷은 변경하지 않고 보존 이력이 없다는 사실을 표시한다. 실제 입력을 화면에서 새로 허용하거나 보정 로직을 바꾸지 않았다.

변경 파일: `backend/input_evidence.py`, 입력 근거/수동 이력 API, 세션·승인 입력 이력 보존, `InputEvidence.jsx`, 앱/스타일/오프라인 경로, 파생 입력 JSON 2개, 생성 스크립트, 신규 Python·화면 단위·E2E.

## 실제 테스트 및 발견 오류

- 신규 147개와 기존 엔진/기록/일정 근거를 포함한 Python **205개 통과**, 6.36초.
- 기존 API·관측 기록 회귀 검사 **10개 통과**, 8.00초.
- 화면 단위 **21개 통과**, 150.7967ms.
- 최신 빌드 통과, 2.25초.
- 최신 데스크톱/모바일 입력 근거 E2E **4개 통과**, 8.1초. 관측 오프라인 입력 변환·이력 없음 및 일반 재현 모의 측정의 시각별 적용/미적용 검사.
- 앞선 일정 근거를 포함한 E2E도 **6개 통과**, 9.5초. 최신 상태의 전체 테스트는 후속 작업 종료 시 다시 실행한다.

신규 검사가 두 실제 문제를 잡았다. 첫 재현 전 수동값 저장 시 날씨 저장소에 구장이 없어 외래키 오류가 나던 문제를 저장 전에 구장을 등록해 수정했다. 이력이 없는 오래된 승인 입력에 나중 세션의 이력이 섞일 수 있던 문제는 승인 스냅샷의 이력만 참조하도록 수정했다. 기존 보정값·조건은 변경하지 않았다.

7월10일 스냅샷에는 관측 일사 0이 없어 최초 신규 경계 검사의 자료 선택이 실패했다. 0과 결측을 명시한 경계 입력으로 바로잡아 두 경우를 엄격히 구분한다. 원래 샘플·스냅샷·기존 테스트는 변경하지 않았다.

- [x] 기존 가정·보정·범위·방법·폴백과 지문 표시.

- [x] 두 스냅샷 입력 근거와 관측 오프라인 흐름 지원.

## 사용자가 직접 확인할 항목

관측 스냅샷 12시 입력 근거에서 0.18MJ/m²→50W/m²와 기간 결측 9시간을 확인한다. 이것이 현장 WBGT 정확도 지표가 아님을 확인한다. 일반 재현에서는 모의 수동값 저장 후 새 재현을 실행해 측정 시각 이전/이후의 적용 상태를 비교한다. 이미 승인한 결과가 나중 입력에 따라 달라지지 않는지 확인한다. 원래 스냅샷의 “이력 미보존”을 “실측을 하지 않았다”는 확정 정보로 해석하지 않는다.
