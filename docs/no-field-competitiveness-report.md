> 이전 기준 기록입니다(2026-10-21 이전: 유소년 범위 상단 판정). 현재 수치와 기준은 [2026-10-21 재계산](recalc-2026-10-21.md)을 보세요. 2026-10-11 재계산(일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정) 기록은 [2026-10-11 재계산](recalc-2026-10-11.md)에 있습니다.

2026-10-06. 실제 측정 자료를 구할 수 없다는 사용자 조건을 적용했다. **현장 정확도 대신 재현 가능한 일정 기술과 판단 근거를 제출의 중심으로 강화했다.** 수상권이나 수상 확률을 입증한 문서는 아니다. 공개 배점이 없고 다른 출품작도 평가하지 않았다.

## 변경 요약

1. 기존 약한 열 노출 우선 탐욕만의 비교에서, 단순4종 중 날짜별 가장 유리한 결과와의 비교로 근거를 강화했다. 같은62일·같은 기본 가정·같은 후보·하드 제약이며 좋은 날만 추려 비교하지 않는다.
2. 원 제약을 바꾸지 않는 읽기 전용 조건 변화 검토를 추가했다. 추정 변화·자료 누락에 따른 권고와 제약을 확인하고 제안/승인 입력을 분리한다. 원래 엔진·정책·운영값·솔버 제한·기존 스냅샷·PDF는 유지했다.
3. 제품의 오프라인 기술 증거 화면, 제출 제안서·주장 대장·심사 요약·질의응답·부록 캡처·README에 더 엄격한 근거와 검증 범위를 반영했다. 기존 불리한1.39% 증가 결과는 참고 비교로 유지한다.
   실제 로컬 관측 스냅샷의 [비교 화면](competition-evidence/captures/stronger-baselines.png)과 [검토 화면](competition-evidence/captures/plan-review.png)을 저장했다. 오류 사유는 팀 휴식·운영시간·일몰·자료 누락처럼 운영자가 읽을 수 있는 한국어로 표시한다.
4. 현장 대조는 자료를 얻을 경우의 장기 로드맵으로 바꾸었다. 이번 제출 전 실측 자료를 준비하도록 요구하지 않는다. 실제 사용·고객·정확도는 미검증이며 기존 기록 도구도 수행 실적이 아니다.

## 공모전에서 설명할 가치

[공식 요강](https://ggsports.spectory.net/innovation/contest?bno=60730)이 다루는 안전·시설 관리와 대회 운영에 맞춰, 열 위험을 일정 대안·연기 사유·승인·기록으로 연결하는 실행 시제품을 제시한다. 실측 없는 계산을 현장 안전 성능으로 소개하지 않고 **제약을 지키는 대안 탐색과 판단의 추적 가능성**을 증거로 보여준다. 단순 방식에 유리한 비교, 모든 날짜와 불리한 비용 공개, 고정 일정의 조건 변화 재검토, 네트워크 없는 전체 시연은 심사자가 직접 확인할 수 있는 장점이다. 이 평가는 자체 경쟁력 판단이며 공식 채점이 아니다.

실측 불가로 남는 약점은 국내 구장의 WBGT 정확도, 공간 대표성, 실제 운영자의 시간·수요와 구매 의사다. 기술 검증으로 이를 대신 인증하지 않는다. 모델 자체의 독자성·국내 최초·특허성·경쟁사 부재도 주장하지 않는다. 반복 가상 배정+4건은 실제 대회4경기를 살렸다는 의미가 아니다. 최종 영상·발표 파일·외부 주소는 여전히 사용자 제출 준비 항목이며 이번 작업에서 제작·배포하지 않았다.

## 내가 확인할 항목

1. 제출 첫 근거로558→562건·14→16일·5.15%와 가상 대회·공통 집합·동일 가정을 제시한다. 기존+56건은 참고 결과로 둔다.
2. 관측 스냅샷 저장 후 오프라인 새로고침하여 새 기술 증거와 조건 변화 검토를 확인한다. 부록을7분 본 발표·3분 시연에 더하지 않는다. 새 질문14/15는 각30초 목표다.
3. 자료 누락은 한 구장/시간 제거이며 관측소 전체 장애나 실제 누락 확률 실험이 아니다. 승인 당시 입력을 따로 확인하고 자동 검토를 실제 운영 결정으로 오인하지 않는다.
4. 실측·운영자 사용·고객·전문가 자문을 수행한 듯 말하지 않는다. 현재 제출할 수 있는 기술 증거와 장기 로드맵을 구분한다.
5. 영상 촬영, 실제 발화·클릭7분 리허설, 신청자 정보/필수 서류/최종 규격과 접수 완료 상태를 직접 확인한다. 실측 자료를 구하는 항목은 요청하지 않는다.
