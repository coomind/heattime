# API허브 AWS 매분자료 1.1 연결 근거

2026-10-05 확인. 기존 제공 ASOS DOCX 요약을 바꾸지 않는다. 이 연결은 별도 공식 [AWS 서비스 페이지](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=239), 페이지가 연결한 [AWS매분자료조회 API명세서](https://apihub.kma.go.kr/getAttachFile.do?fileName=AWS%EB%A7%A4%EB%B6%84%EC%9E%90%EB%A3%8C%EC%A1%B0%ED%9A%8C_API%EB%AA%85%EC%84%B8%EC%84%9C.pdf) 1~3쪽, [이용 안내](https://apihub.kma.go.kr/apiInfo.do)를 근거로 한다. 실제 관측 API는 에이전트가 호출하지 않았다.

## 문서 계약

GET 요청 주소는 `https://apihub.kma.go.kr/api/typ01/cgi-bin/url/nph-aws2_min`.

| 변수 | 공식 설명 | 앱 사용 |
|---|---|---|
| tm1 | 시작 KST YYYYMMDDHHMI, 생략하면 종료와 같음 | 생략 |
| tm2 | 종료 KST YYYYMMDDHHMI, 생략하면 현재 시각 | 생략 |
| stn | 지점번호, 0/생략은 전체 | 119 기본, 0 금지 |
| disp | 0 고정길이, 1 CSV | 0 |
| help | 0 시작/끝/변수명, 1 설명 추가, 2 값만 | 0 |
| authKey | API허브 인증키 | 서버에서만, URL 출력·저장 없음 |

전체 지점 구간은 10분, 한 지점은 하루 이내. 이 앱은 현재 시각의 한 지점만 요청한다. 자료 생산 주기는 분이며 전달 지연의 상한이나 현장 WBGT 제공을 의미하지 않는다. 기본 수원 119는 기존 제공 지점표와 공식 AWS 응답 예시의 119행으로 확인했다. 다른 지점의 위치·대표성·가까움은 자동 판단하지 않는다.

명세서 출력 표의 관측 시각은 TM이며 응답 예시 헤더에는 YYMMDDHHMI라고 적혀 있다. 둘만 허용한다. 고정 순서 18필드:

`YYMMDDHHMI STN WD1 WS1 WDS WSS WD10 WS10 TA RE RN-15m RN-60m RN-12H RN-DAY HM PA PS TD`

| 사용 필드 | 단위·의미 | 처리 |
|---|---|---|
| 관측 시각 | YYYYMMDDHHMI KST | 시간대 명시 |
| STN | 지점번호 | 요청 번호와 대조 |
| TA | 1분 평균 기온 ℃ | 기존 내부 범위 검사 |
| HM | 1분 평균 상대습도 % | 비율로 변환하지 않음 |
| WS10 | 10분 평균 풍속 m/s | WS1/돌풍과 구분 |
| PA | 1분 평균 현지기압 hPa | 참고 표시 |
| PS | 1분 평균 해면기압 hPa | 참고 표시 |
| RN-60m | 60분 누적 강수 mm | 기존 강수 감쇠 입력 |

관측값 -50 이하는 관측 없음/오류라는 명세 설명을 적용한다. TA/HM/WS10 결측은 계산을 거절하고 PA/PS/RN-60m 결측은 null로 표시한다. 0은 유효값이다. 이 응답에는 일사·운량·WBGT가 없다. 추측한 필드명이나 단위 변환을 추가하지 않는다. 명세의 오류 코드 401은 인증키 오류, 403은 활용신청 필요이다. 앱은 HTTP 상태를 고정 안내로 변환하고 원문 본문·예외 메시지를 표시하지 않는다. 다른 응답 구조는 거절한다.

## 앱의 해석·운영 설계 (API 규정과 구분)

- 기본 합성 점검, 사용자 API 선택 후 갱신 버튼을 눌렀을 때만 키 로드·호출. 시작·재현·스냅샷에서는 키를 읽지 않는다.
- .env는 서버 코드 위치 기준 프로젝트 루트. KMA_APIHUB_KEY만 사용하고 OS 환경 설정도 지원한다. 키는 응답·로그·DB·프론트엔드에 포함하지 않는다. 리다이렉트도 거절한다.
- 기존 엔진을 호출한다. 일사/운량 없음은 기존 운량 0.7 추정 가정, 풍속 입력 높이는 기존 10m 가정, 기압은 기존 설정 1013.25hPa 기본을 유지한다. 관측 PA/PS로 엔진 설정을 바꾸지 않는다. 구장 보정·연령 상단 판정·추정 범위도 기존 설정 그대로다.
- 관측소 입력 1개를 등록된 구장들에 공유한다. 현장 대표성과 공간 오차는 미검증. 현재 관측은 미래 경기의 예보를 대신하지 않고 재현/승인 기록에 주입하지 않는다. 수동 측정 보정은 이 별도 최신 화면에 적용하지 않는다.
- 관측 시각/가져온 시각/화면 확인 시 경과 분을 표시하고 실패 때 이전 성공 자료는 그대로 날짜를 표시한다. 원문 관측 응답은 저장하지 않는다. 재시작하면 메모리 관측은 사라진다.
- 앱 전체 최소 60초 호출 간격과 동시 요청 공유. 호출 간격·일일 횟수/바이트는 SQLite에 유지한다. 하루 구분 KST는 앱의 설계이며 API허브의 계정 집계 시간대를 확정하는 설명이 아니다.
- 사용자 안내 및 공식 안내의 일 20,000회·5GB에 맞춰 보수적으로 5,000,000,000바이트를 적용한다. 단일 응답 1MiB 상한, 호출 전 이 용량을 예약하고 성공 응답 크기로 조정한다. 통신 실패는 예약량을 유지하므로 표시 바이트는 실패 시 보수적 집계다. 키 누락은 호출 횟수를 늘리지 않는다.
- 사용량은 이 저장소만 집계한다. 다른 앱/서버/저장소의 같은 키 사용량은 알 수 없으며 전체 사용량은 API허브에서 확인해야 한다. 한 서버의 60초 간격은 하루 약 1,440회 이하로 제한하지만 자동 조회는 제공하지 않는다.

## 직접 확인 필요

사용자가 AWS 1.1 활용신청을 완료하고 일반 로컬 화면에서 연결·관측 시각·필드 제공 여부를 확인한다. 현재 시각에 자료가 없거나 공식 헤더와 실제 응답이 다르면 값을 추측해 수용하지 않는다. 키·URL을 지운 응답 샘플을 제공해 문서 계약과 대조한다. 현장 측정기 대조·일사 관측 연결·공간 대표성 검증·미래 예보 연결은 미완료다.
