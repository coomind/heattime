## 가이드에 없던 시간·일사 구간의 추가 근거

[기상청 ASOS 시간 관측 공식 설명](https://apihub.kma.go.kr/apiList.do?apiSeq=2)의 시간자료 출력 설명은 관측시각을 KST, 일사를 MJ/m²로 표시한다. 이 물리 자료 설명을 시간대 근거로 사용한다. 해당 페이지의 다른 API 주소나 변수명을 이 프로젝트의 수집기로 옮기지 않는다.

[국립기상과학원 연구진의 원 관측 연구 §2.2~2.3](https://doi.org/10.14191/Atmos.2020.30.1.059)은 기상청 전천일사계의 정시 대표값이 기준시각 이전1시간 자료이며, 서로 다른 시각 해상도의 추정을 같은 시간 구간으로 평균하여 비교하는 방법을 설명한다.

따라서 이 샘플의 `icsr`는 **정시 이전1시간의 일사 에너지(MJ/m²)**로 처리한다. 하루 시작부터 증가하는 누적값이 아니다. 내부 W/m²는 `icsr × 1,000,000 ÷ 3600`으로 변환한 **한 시간 평균 복사조도**이며 순간 관측 W/m²라고 표시하지 않는다. 원 에너지, 구간 시작/끝, 변환 의미를 WeatherPoint의 근거에 보존한다. 원본의 시간별 값이 낮 시간 중 감소하기도 하는 것은 일 누적값과 맞지 않는 추가 관찰이며, 이 패턴만으로 구간을 확정하지 않았다.

## 적용과 한계

- 위험 시각 h의 WBGT에는 구간[h, h+1)의 일사, 즉 h+1시에 보고된 `icsr`와 같은 시각의 운량·강수를 적용한다(2026-10-11 재계산: 일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정 후 전 수치 재생성; 이전에는 h시 보고값인[h−1, h] 구간을 적용해 1시간 늦게 반영했다). 일사가 결측이면 같은 구간의 맑은 하늘 평균(1분 적분)으로 추정한다.
- 추정 일사 비교도 관측과 같은 정시 이전1시간 구간의 추정 평균을 사용한다. 정시의 순간 추정과 직전1시간 관측 평균을 그대로 비교하지 않는다. 비교 쌍이 같으므로 정렬 변경 후에도 비교 지표는 변하지 않았다.
- 전운량은 관측10분위/10을 공식의 운량 비율로 사용한다. 예보 SKY 코드를 만들어 넣지 않는다. 강수는 관측 `rn`이 있을 때만 사용한다. 구름/강수 감쇠식과 계수는 기존 값을 유지한다.
- 일사 빈 값은 관측0으로 바꾸지 않고 비교에서 제외한다. 빈 값의 이유가 야간 미제공인지 장비 결측인지는 샘플과 가이드만으로 구분하지 않는다.
- 구장 좌표·기압·고도·구장 보정·표면 보정·연령 판정·불확실성은 원래 운영값이다. 수원 관측을 가상 구장에 적용하므로 구장의 실제 측정이나 WBGT 실측 검증으로 주장하지 않는다.
- 일사 비교의 좌표는 기존 가상 구장A 좌표이다. 관측소 정확한 좌표라고 주장하지 않으며 공간 차이와 구간 끝 시각의 구름/강수를 그 1시간 동안 고정하는 근사도 보고한다.
- API 키·URL·헤더·예외 원문은 정규화 자료에 복사하지 않는다. 필요한 관측 필드와 확인된 지점·기간·수집시각·원본 지문만 보존한다.
