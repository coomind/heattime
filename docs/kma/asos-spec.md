## 서비스와 요청 주소

- REST GET, ServiceKey 인증. XML/JSON 지원.
- 서비스 주소: `http://apis.data.go.kr/1360000/AsosHourlyInfoService`
- 목록 조회: `http://apis.data.go.kr/1360000/AsosHourlyInfoService/getWthrDataList`
- 원문은 HTTP 주소와 전송 암호화 없음으로 표시한다.
- 전일(D-1)까지 제공, 전일 자료는 조회시간 기준11시 이후 조회 가능.
- 최대 메시지1000K byte, 평균 응답2000ms, 초당 최대30tps로 기재.

## 응답 예제 구조와 품질 플래그

원문 XML 예제의 구조:

```text
response
  header: resultCode, resultMsg
  body: dataType, items/item, numOfRows, pageNo, totalCount
```

각 item의 필드는 위 응답 표 참조. 예제 tm은 `2019-01-20 01:00`, 필드 표 예시는 `2010-01-01 10`이다.
정상 응답 코드는 에러 표에서 `00`, XML 예제에서는 `0`으로 나타난다.
품질 플래그 표: 정상 `null`, 오류 `1`, 결측 `9`. 필드 표 샘플은 `0`이므로 이 차이를 임의로 통일하지 않는다.
icsr는 선택 필드이며 단위는 MJ/m2. 원문의0.0 일사값은 빈 필드가 아니다.
gndSttCd는2016.7.1.00시 관측 종료로 이후 값이 조회되지 않는다고 기재한다.
