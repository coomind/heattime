## 확인 가능한 근거

[공식 요강](https://ggsports.spectory.net/innovation/contest?bno=60730)은 스포츠산업 앱/웹, 대회 운영·관리와 안전·시설 기술, 출시 전 시제품을 허용한다. 제출 자료는 소개서/제안서와 시연 포함7분 발표, 서비스 링크·사진·활용 영상 등이다. 점수·심사 과정은 공개되지 않는다. 따라서 임의 점수나 수상 확률을 만들지 않았다.

- [심사자 증거 묶음](competition-evidence/proof-pack.md), [기계 판독 대장](competition-evidence/verified-claims.json): 고정 분석·원본/검사 지문·전체 실행 영수증을 연결한다. 기존 발표/제출/비교 검사, 현재 관측 입력 지문, 테스트 시작 코드 지문, 기존 검사 수와 실패/중단/재시도 실패 여부가 맞아야 재생성된다. 해시와 자체 테스트는 제3자 인증이 아니다.
- 수원119의1488시간을 사용한62일 가상 대회,7월10일의15배정/0연기·공통15경기6114→4319, 중앙 최고32.043℃(범위30.543~33.543℃): 기존 원자료 그대로다. 새로운 현장 결과가 아니다.
- 같은 제약의 탐욕 대비 CP-SAT 배정 합계506→562(+56건), 완전 배정0→16일: 조합 탐색의 조건부 기술 근거다. 공통 열 노출130617→132430(+1.39%)의 불리한 비용도 공개한다. 사람·경쟁 제품·건강 효과와 비교한 결과는 아니다.
- 62일 중46일에 같은 날15경기 전부 배정 실패, 0배정3일(8월4·5·6일)은 구분한다. 가정은 경기장 보정 +2.5℃, 유소년 추정 상단값 판정, 동일 관측소 1곳 공유, 이 가상 대회의 대진·휴식·운영시간·일몰 제약이다. 실제 개최 불가 일수로 일반화하지 않는다.

## 내가 확인할 항목과 남은 실제 증거

1. 일반 실행 → **검증 기록**에서 가상 예시 입력·시간 합계·부정 의견·제외 사유·JSON/CSV를 확인한다. 실제 자료가 없으면 실제로 바꾸지 않는다.
2. [계획](submission/validation-plan.md)에 따라 운영 실무자3~5명의 동의를 직접 얻고 같은 대진·정책·운영 조건으로 두 순서를 수행한다. 준비 시간을 제외하지 않고 중단·거절 의견도 남긴다. 역할·구매 결정자를 구분하며 호응을 계약·시장 수요로 과장하지 않는다.
3. 현장 WBGT는 별도 측정기가 필요하다. API 키는 기온·습도·바람 입력을 제공하며 현장 WBGT를 측정하지 않는다. 실제 좌표·표면의 구장, 기기 교정·위치·높이·동일 시각·프로토콜을 전문가와 확인한 뒤 최신 추정 보관 자료와 대조한다. 시간 불일치를 숨기지 않는다.
4.10월 온화한 조건의 현장 대조로 여름 폭염 정확도를 입증하지 않는다. 폭염 조건 원자료나 다음 계절의 검증은 별도 과제다. ±1.5℃ 범위와 공간±1℃ 시나리오를 검증된 오차 범위로 쓰지 않는다.
5. 개인정보·키·요청 URL은 입력하지 않는다. 원자료는 익명 코드로 별도 보관하고 DB/다운로드를 공개 저장소에 넣지 않는다. 공개용 자료는 동의 범위·익명화와 모든 검토 제외 사유를 직접 확인한다.
6. 실제 현장 효과·전문가 자문·인터뷰·유료 고객·기본 API 안정성을 아직 확보한 것으로 쓰지 않는다. 관측 시연의 영상 촬영·제출 형식·외부 증빙은 [접수 확인 목록](submission/submission-checklist.md)에 따라 사용자가 준비한다. 발표 파일·배포·발송은 이번에 수행하지 않았다.

현재의 경쟁력은 **관측 입력의 제약 만족 일정 대안 + 운영자 판단 근거 + 불리한 결과 공개 + 재현 가능한 검증**이다. 운영자 효용·국내 현장 정확도·구매 의사와 수상권 자체는 실제 자료를 확보한 뒤에만 평가할 수 있다.
