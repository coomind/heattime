> 이전 기준 기록입니다(2026-10-21 이전: 유소년 범위 상단 판정). 현재 수치와 기준은 [2026-10-21 재계산](recalc-2026-10-21.md)을 보세요. 2026-10-11 재계산(일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정) 기록은 [2026-10-11 재계산](recalc-2026-10-11.md)에 있습니다.

2026-10-06. 수상 경쟁력을 위한 추가 점검에서12팀·1일 대진의 결과를 다른 규모에 확대할 수 있는지 확인했다. 실제 구장 실측 없이 할 수 있는 내부 기술 검증이다. **추가 검사에서 불리한 결과를 발견했으며, 더 개선할 일이 없다는 결론을 내리지 않는다.**

## 변경 파일 요약과 방법

`scripts/analyze_tournament_scale.py`는 기존 `scripts/benchmark_schedule.py`의16팀·27경기·2일 가상 대진을 그대로 사용한다.7월1~2일,3~4일 순서로8월30~31일까지 겹치지 않는31개 이틀 구간을 모두 검사했다. 날짜와 대진은 풀이 전 고정했고 더 나은 해를 고르려고 반복 풀이하지 않았다.

실제 ASOS 수원119의 커밋된 정규화 입력을 사용한다. 동일 관측소를3개 가상 구장에 공유하고 구장+2.5℃·유소년 상단값·기본 범위·정책·휴식·운영시간·일몰·솔버10초 제한을 유지했다. 자료 수집·키 로드·.env 열기 없이 별도 임시 DB에서 재현했다. 기존12팀 결과/스냅샷/PDF/엔진/운영값을 바꾸지 않았다.

엔진은 기존 CP-SAT 실행과 필요 시 기존 탐욕 폴백이다. 단순4종도 같은 후보/제약으로 계산한 후 최대 배정·그 안에서 기존 가중 비용 최소를 선택한다. 공통 경기만 열 노출을 비교하고 미배정은 별도 기록한다. 모든 결과·배정 목록·연기 사유·지문·상태·시간은 [원자료](competition-evidence/tournament-scale-analysis.json)에 있다.

## 실제 실행 결과

분석 전체348.478초. 이 시간은31회 기상 재현·최적화·단순4종 비교·검사를 포함하며 제품의1회 응답 시간이나 사람의 업무 시간이 아니다.

| 항목 | 날짜별 유리한 단순 기준 | 기존 엔진 |
|---|---:|---:|
|31개 가상 대회 배정 합계 |598|596|
| 연기 합계(31×27경기) |239|241|
|27경기 전부 배정한 이틀짜리 대회 |13|14|
| 공통 경기 열 노출 합계 |148791|144293|

공통 열 노출은3.023% 낮았지만 **배정 합계는2건 적었다.** 배정 우위6구간·동일23구간·열세2구간. 공통 경기가 없는 구간1개도 포함해 공개한다. 하나의 합계만 골라 성공을 주장하지 않는다. 완전 배정 대회 수14는 이틀 구간의 수이며, 기존12팀의 완전 배정16일과 합치거나 같은 척도로 직접 비교하지 않는다.

| 결과 상태 | 구간 수 | 해석 |
|---|---:|---|
| CP-SAT OPTIMAL |12| 모델의 배정/가중 비용 최적해 확인 |
| CP-SAT FEASIBLE |18| 시간 제한 안의 유효 해, 최소 연기·비용 최적 미확정 |
| greedy-fallback |1| 기존 폴백 결과, 최적성 주장 불가 |

최적화 호출의 준비·검사 포함 시간 중앙10.637초·최대11.2187초. 솔버 탐색 제한10초는 원래대로이며 전체 응답이 정확히10초 이내라는 뜻이 아니다. 한 PC의 한 실행 결과로 장기 지연·가용성을 검증하지 않았다. 기존 합성 조건의16팀 성능 검사와 다른 관측 입력 검사다.

## 가장 중요한 불리한 사례

| 관측 구간 | 엔진 상태 | 엔진 / 단순 배정 | 단순 선택 |
|---|---|---:|---|
|7월9~10일 |FEASIBLE|16 / 27|선행 경기·기존 가중 비용 우선 |
|8월16~17일 |폴백|26 / 27|선행 경기·기존 가중 비용 우선 |

검사에서 단순 방식의27배정 역시 같은 하드 제약과 권고 속성/점수를 통과했다. 따라서 이 두 구간의 엔진 연기를 전부 날씨나 대진 때문에 피할 수 없었다고 말하면 안 된다. **특히7월9~10일의16배정 결과는 최소 연기 해가 아니다.** FEASIBLE·폴백 결과에서 비교한 단순 방식보다 좋은 배정이 선택된다는 보장이 현재 구현에는 없다.

이는 WBGT 단위 오류로 확인한 문제나 제약 위반은 아니다. 정해진 탐색 제한 내 해/기존 폴백의 품질 문제다.12팀의+4건·5.15%를 대진 일반의 우위로 확대하는 근거가 부족함을 보여준다. 최근 작업의 엔진/정책 불변 범위를 지켜 실제 최적화 엔진은 수정하지 않았고, 더 유리한 재실행 결과로 덮어쓰지 않았다.

두 번째 가상 대진의31개 관측 조건을 검사한 것이며 전체 대회에 대한 일반화 성능을 입증한 결과가 아니다.

## 다음 개선 후보와 이번 작업의 경계

가장 구체적인 코드 개선 후보는 **FEASIBLE·폴백 결과를 동일 제약을 통과한 단순 후보와 비교해, 배정 수를 먼저 높이고 동수일 때 기존 가중 비용을 줄이는 검증된 대안을 선택하는 방식**이다. 정책·운영값을 낮출 필요는 없지만 실제 엔진 결과/상태/승인 기록의 동작을 바꾸는 수정이다. 이번에는 엔진을 임의로 변경하지 않고 독립 평가와 다음 구현의 구체적 대상으로 정리한다.

수정 시에는 이 두 사례를 재현하는 테스트를 먼저 추가하고, 동일 후보 공간·목적 우선순위·제약·총 대기 시간을 확인해야 한다. 선택한 단순 대안을 OPTIMAL로 표시하지 않아야 하며, 전체31구간과 기존12팀/승인/PDF 회귀 검사를 통과해야 한다. 더 긴 탐색 제한으로 좋은 결과를 내는 식으로 해결하지 않는다. 모든 단순 방법/모든 대진의 최적성을 보장한다는 요구도 아니다.

추가 기능이 자동으로 수상 경쟁력을 높인다고 보지 않는다. 현재는 이 구체적 결과 품질 문제, 최신 관측 기본 타임아웃, 제출 전달력/실행 증빙을 다음 검토의 우선 대상으로 본다. 고객·현장 정확도는 코드로 실적을 만들 수 없고 실제 측정 확보 불가 조건은 유지한다.

## 실제 테스트와 수용 기준

새 `tests/test_tournament_scale.py`의32개 검사로31구간 모두의 새 입력 지문,144개 구장/시간 입력, 배정/연기27개 전체, 후보/권고/점수/제약, 공통 경기, 유리한 기준 선택, 실제 상태와 기본값을 검사한다. OPTIMAL인 경우만 같은 공간의 단순 해보다 배정/목적값이 뒤지지 않는지도 검사한다. FEASIBLE에 임의의 최적성 단언을 넣지 않는다. `scripts/check_tournament_scale.py`는 기존 검사를 대체하지 않는 추가 정합성4개다.

실제 실행 결과와 최종 전체 검사 수는 [인계 작업 보고](ai-review-handoff-report.md)에 확정 기록한다.

추가 테스트32개는 실제로48.96초에 모두 통과했다. 추가 정합성4개도 통과했다. 첫 정합성 검사는 보고서의 일반화 한계 문구 누락을 검출했으며, 한계를 문서에 추가해 해결했다. 검사 조건을 지우거나 약화하지 않았다.

- 모든 날짜의 사전 지정·동일 정책/운영값/제약·기존 결과 불변: 통과.
- 불리한 결과·FEASIBLE·폴백·최소 연기 미확정 공개: 통과.
- 대진 일반에 우위가 보장된다는 주장: **입증 실패**, 주장하지 않는다.
- 실제 운영자·현장 정확도·수상권: 미검증.

## 내가 확인할 항목

1. 다른 AI에12팀 우위뿐 아니라16팀의596 대598건, 두 열세 사례를 함께 전달한다.
2. FEASIBLE/폴백 연기를 모두 물리적으로 불가피했다고 설명하지 않는다. 최소 연기 미확정 상태를 확인한다.
3. 새 수치를 대표7월10일 시연·가정 민감도와 섞지 않는다. 대진/기간/비교 집합이 다른 내부 기술 검사다.
4. 다음 엔진 수정 여부는 위 재현 사례·목적 우선순위·상태 고지·회귀 검사로 판단한다. 실측 자료 확보를 해결 조건으로 요구하지 않는다.
