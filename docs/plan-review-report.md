# 조건 변화 검토와 실측 없는 기술 증거 화면

> 2026-10-11 재계산 안내: 이 문서의 수치는 작성 당시 기준입니다. 일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정 이후의 현재 수치는 [재계산 보고](recalc-2026-10-11.md)를 따릅니다.

2026-10-06. [분석 근거](no-field-analysis-report.md)를 제품에서 읽고 현재 제안/승인 일정에도 적용할 수 있게 했다.

## 변경 요약

- 재현 모드의 **실측 없이 확인한 기술 근거**에서 단순 방식4종의 전체62일 비교, 날짜별 가장 유리한 기준, 조건 변화 결과·한계를 확인한다. 기존 열 노출 우선 비교와1.39% 증가 표시를 유지했다.
- 재편성 비교의 **조건 변화 검토**는 현재 제안 또는 승인 당시 입력을 읽는다. WBGT −1/0/+1/+2℃, 판정값이 가장 높은 배정 구장·시간 자료 하나의 누락을 검사하고, 중지/자료 누락/권고 변경 경기와 기존 하드 제약 오류를 공개한다. 기본 정책과 기존 범위·값·시각을 변경하지 않는다.
- 경기별 기준 차이는 해당 연령/정책/연령 단계 상향까지 반영한 중지 기준에서 원 판정값을 뺀 값이다. 추정 중앙값과 low~high를 함께 표시하며 안전성·실제 오차·시간 여유 지표로 해석하지 않는다.
- 승인 당시 동결 입력을 사용하고 승인 후 화면을 초기화하여 새 데이터와 섞이지 않게 했다. API는 GET만 허용하며 기록·날씨·승인·솔버를 변경하지 않는다.
- 합성·관측 기존 스냅샷은 별도 보조 자산만 추가했다. 원본 및 PDF를 수정하지 않았고 입력 지문·세션 ID 검사가 다른 자료 연결을 차단한다. 신규 자료도 기존 시연 캐시에 들어간다.

## 실제 테스트 결과

- API 테스트2개 통과(2.94초): 합성/관측, 동결 승인 참조, 저장 내용 불변, 잘못된 보기422/없는 세션404/POST405/미승인422, 두 보조 자산과 동일한 결과.
- Node25개 통과: 기존21개 유지 + 신규4개. 제안/승인 순서·버전 불일치·누락 자산·반환 사본 독립·62일 합산·유리한 기준 선택 검사.
- 브라우저4개 통과(10.7초): 데스크톱/모바일 × 합성/관측. API요청0·오프라인 새로고침·전체62행·5개 시나리오·경기 기준 차이·승인 후 보기·가로 넘침 없음.
- 프론트엔드 빌드 통과(3.32초), 번들 크기 경고 없음. 신규62일 분석 자산572.13kB/압축54.09kB는 펼칠 때 불러오는 자료다. 최초 캐시 준비 용량은 추가됐으며 전송 시간 개선을 실측했다고 주장하지 않는다.
- 전체 반복 검사는 [종합 보고](no-field-competitiveness-report.md)에 기록한다. 기존 TestClient 사용 중단 예정 경고1건은 동작 변경 없이 해결됐다고 주장하지 않는다.

## 수용 기준 / 내가 확인할 항목

읽기 전용·정책/운영값/엔진 불변·기존 테스트 유지·추정 범위와 가정 고지·오프라인 흐름·승인 입력 분리: 모두 통과.

1. 관측 스냅샷 저장 후 새로고침하고 재현 모드의 신규 기술 증거를 펼쳐558→562건·14→16일·5.15%와 전체 날짜를 확인한다.
2. 재현→재편성 제안→조건 변화 검토에서 제안/승인 구분과 원래 추정 시나리오 통과, 자료 누락 시 재검토 표시를 확인한다.
3. 자료 누락은 한 구장·한 시간 입력 제거이며 세 구장의 동일 관측소 전체 장애를 모사하지 않는다. 추정 이동은 물리 입력 재계산이 아니다.
4. 시연3분에 새 부록을 더하지 않는다. 실제 측정이 없어도 기술 시제품 검증을 설명하되 현장 정확도·실제 사용 성과를 약속하지 않는다.
