2026-10-05. 경기별 변경 내역에 자동 제안/승인 일정 근거 버튼을 추가했다. 원래 상세 버튼은 유지한다. 새 화면은 기존 권고 함수와 하드 제약 검사로 WBGT 추정·범위, 권고 반영 종료, 휴식·진출 가능 팀·선행 경기·구장 정리·운영 마감·일몰을 표시한다. 수정 전 자동 제안과 실제 승인 일정, 거절·연기를 구분한다. 승인 일정은 승인 시점의 고정 입력을 사용한다.

변경 파일: `backend/evidence.py`, 상세 API, `MatchEvidence.jsx`, 기존 앱/변경 표/스타일, 오프라인 상세 경로, `scripts/build_snapshot_evidence.py`, 파생 상세 JSON 2개, 새 Python·화면 단위·브라우저 테스트. 파생 JSON은 기존 스냅샷에서 읽기 전용으로 생성했으며 재최적화하지 않았다.

## 실제 테스트

- 새 Python 상세 검사 **34개 통과**(2.76초). 양쪽 스냅샷 30경기 전부, 기존 권고·제약과 일치, 승인 입력 고정, 거절/수정 구분, 읽기 전용 API 검증.

최초 신규 테스트는 준결승 ID를 잘못 기재했고 합성 스냅샷의 `g1-1`이 배정됐다고 잘못 가정했다. 실제 ID `semi1/2`, 합성 배정 `g4-3`을 확인해 신규 검사 대상을 바로잡고 연기 상세 검사도 추가했다. 기존 테스트·스냅샷·수치·엔진을 바꾸지 않았다.

## 사용자가 직접 확인할 항목

관측 스냅샷에서 `g1-1 자동 제안 근거`의 09:00 제안과 원래 10:00를 비교한다. 결승에서 진출 가능 팀 휴식과 일몰 마감을 확인한다. 합성 스냅샷에서는 `g4-3` 배정과 `g1-1` 연기 사유가 구분되는지 확인한다. 수정 승인 시 자동 제안 근거와 승인 일정 근거가 서로 다르게 표시되는지 확인한다.
