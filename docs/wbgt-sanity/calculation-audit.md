# WBGT 계산 검증 작업 단위

2026-10-05. 정책·운영값·안전 문구·기존 테스트를 수정하지 않았다. `.env` 접근, 수집, 배포, 로그인, 실제 메시지 발송 없음.

## 변경 요약

- `scripts/wbgt_sanity.py`: 관측 입력 62일의 4,464개 구장×시간 추정을 새로 계산하고 이전 입력 해시·날짜별 최대값과 대조. 최고 5일과 7월10일의 단계별 입력/출력·근사 비교·단일 입력 비교 저장. 분석 가정만 메모리에서 달리하는 민감도 기능 포함.
- `scripts/wbgt_solar_probe.c`: 수정하지 않은 lwbgt1.0.1 공개 C 소스의 내부 일사 분리 함수를 노출하는 분석 전용 래퍼. 설치 DLL을 교체하지 않는다.
- `peak-traces.json`·`peak-tables.md`: 여섯 시각의 추적 가능한 계산 결과. `pressure-evidence.json`: 원본 해시를 확인한 관측 기압 필드만 명시적 허용 목록으로 보관; 앱 어댑터는 변경 없음.
- `tests/test_wbgt_sanity.py`: 기존 테스트와 별도로 실제 입력의 단위/인수 순서·풍속 보정/하한·성분 합·일사 에너지 보존·저자 예제·최대일 선택을 검사.

## 확인 결과

8월6일16시(가상B)의 관측 입력은35.6℃·47%·0.3m/s·현지기압999.3hPa·이전1시간 일사1.49MJ/m². 변환 일사413.888889W/m², 2m 풍속0.217434m/s. Tnw30.760340℃, Tg52.346489℃, 보정 전WBGT35.561535℃. 경기장+2.5℃를 더한 중앙값38.062℃, 범위36.562~39.562℃. **38.062℃는 관측 WBGT가 아니다.**

관측소 입력을 가상 구장 좌표에 적용한 보정 전 모델 값을 “관측 입력 기준”으로 부른다. 관측소의 실제 위치에서 WBGT를 실측한 값이라는 뜻이 아니다. 표의 직달·산란 값도 별도 관측이 아니라 모델 내부 분리 추정이다. 모든4,464개는 주 엔진을 사용했고 폴백은0개였다.

단위/변환/입력 순서에 명백한 버그는 확인되지 않았다. 풍속 높이는 명세의10m 입력 가정이며 제공된 ASOS 가이드만으로 실제 센서 높이를 확정할 수 없다. 엔진이2m로 보정한 뒤 라이브러리에도2m로 전달하여 이중 보정하지 않는다. 최소0.13m/s를 적용한다. 원본 기압pa/ps는hPa이고, 엔진은 관측기압 대신 명세 초기 설계의1013.25hPa 가정을 사용한다. 이를 정확한 현장 기압으로 주장하지 않는다.

일사MJ/m²×1,000,000/3,600은 이전1시간 평균W/m²이며 일누적값을 미분하거나3,600배 중복하지 않는다. 현재는 기록된 대표값 가정으로 정각 태양 위치(`averaging_minutes=0`)와 결합한다. 라이브러리 문서는 원자료 평균기간에 맞춘60분을 권한다. 따라서 시간대표성 한계는 남는다. 분석용60분 입력은 같은 종료시각에서 태양 위치만30분 앞당긴다(기온·습도·풍속은 동일). 여섯 대상의 차이는−0.112213~+0.097507℃로38℃ 피크의 원인이 아니며, 시간평균을 시각별 정밀 WBGT로 검증한 것은 아니다. 이를 단위/변환/인수 버그로 취급해 엔진의 기존 대표값 설계를 바꾸지 않았다.

공개 소스 고정 커밋 `e4b1298fcee27faa459f2eab0c2ef766ce2f34d7`을 MinGW GCC로 별도 컴파일. 유효풍속·Tg·Tnw·Tpsy·WBGT의 출력 차이는 대상6개 모두0.0. 다른 입력의 일반적 완전 동등성이나 실측 정확도를 증명하지는 않는다. 소스의 흑구 직경0.0508m·표면 알베도0.45·수렴 허용0.02℃·최소풍속0.13m/s는 모델 상수다. 라이브러리의5.08cm 흑구 출력을15cm 표준 흑구 실측으로 오인하지 않는다. 이 상수는 수정하지 않았다.

독립 비교는 저자의 Stull 통풍습구 근사식과 `0.7Tw+0.3Ta` 그늘 근사를 사용했다. 자연습구를 통풍습구로, 그늘 흑구를 기온으로 근사한 비교값이며 야외 WBGT 실측 검증이나 대체 엔진이 아니다. 8월6일 차이는 자연습구 복사+3.505597℃, 습구식 차이−0.525016℃, 흑구 복사+3.349298℃, 경기장 보정+2.5℃로 설명된다. 그늘 근사29.231657℃를 정답으로 놓고 야외 모델을 낮추지 않았다.

## 근거

- 입력 단위·ABI: [lwbgt1.0.1 ABI 문서](https://github.com/zyf0717/lwbgt/blob/v1.0.1/docs/ABI.md), [입력 준비 문서](https://github.com/zyf0717/lwbgt/blob/v1.0.1/docs/INPUTS.md). 설치 패키지의 `_types.py`/`_ffi.py`와 실제 `Input` 전달 내용을 함께 대조.
- 물리·일사·풍속 처리: [고정 C 소스](https://github.com/zyf0717/lwbgt/blob/e4b1298fcee27faa459f2eab0c2ef766ce2f34d7/src/wbgt.c) `calc_wbgt`, `calc_solar_parameters`, `Twb`, `Tglobe`, `est_wind_speed`.

- 독립 습구 근사: [저자 Stull의 Practical Meteorology, p95 식4.19와20℃·50% 예제](https://www.eoas.ubc.ca/books/Practical_Meteorology/prmet102/Ch04-watervapor-v102b.pdf); [원 논문 DOI](https://doi.org/10.1175/JAMC-D-11-0143.1). 저자의 책에서 식·℃/%·라디안·해수면 근사를 대조했다.
- [CCOHS의 복사·흑구·그늘/햇빛 WBGT 설명](https://www.ccohs.ca/oshanswers/phys_agents/humidex.html). 통풍습구/기온으로 자연습구/흑구를 근사하는 한계를 명시했다.
