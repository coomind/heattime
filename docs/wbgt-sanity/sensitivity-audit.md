# WBGT 운영 가정 민감도 작업 단위

2026-10-05. 분석 전용 메모리 입력만 변경했다. 정책 파일·기본 보정값·유소년 설정·휴식·경기 길이·시간 제한·안전 문구는 그대로다.

## 변경 요약

- `scripts/wbgt_sanity.py`의 분석 변형은 기존 관측을 유지하고 경기장 보정, 상단/중앙 판정, 가상의 구장별 WBGT 편차만 비교한다. 연령을 성인으로 바꾸지 않아 U12 휴식60분은 모든 경우에 유지한다.
- `sensitivity-results.json`: 기본62일 근거 + 새로 푼9개 가정×62일 결과, 배정/연기/증명 상태. 실제 실행 때 각 상세 일정의 모든 하드 제약·경기 합계·연기 최소 우선 페널티를 검증했다.
- `tests/test_wbgt_sanity_analysis.py`: 원세션 불변, 운영값 불변, 실제 관측 근처 경계에서 표시 반올림 전 판정, 잘못된 구장ID 거부를 검사.
- `tests/test_wbgt_sensitivity_results.py`: 전체 가정/62일 누락 검사, 집계/증명 상태, 상세 일정의 제약·연기 사유·공통 경기 열 노출 재계산 검사.
- `reproduce.md`: 기존 관측만 쓰는 PowerShell 재현 절차. 설치 DLL 교체·수집·실제 배포 없음.

## 분석 구현 경계 검사

이번에 만든 분석 도구의 첫 버전은 표시용0.001℃ 값을 옮긴 뒤 판정했다. 기존 생산 엔진은 원래 반올림 전에 판정한다. 관측7월9일00시의 분석+3.75℃ 사례에서27.999591827℃가 표시28.000℃로 바뀌면 단계2를3으로 잘못 판정할 수 있음을 신규 테스트로 재현했다. **신규 테스트1개 실패를 먼저 확인한 뒤 분석 도구만 수정**하여 실제 라이브러리의 반올림 전 출력으로 판정하도록 했다. 테스트를 삭제/완화하지 않았다.

이 차이는해당 날짜00시의3구장뿐이었다. 모든10가정×62일×3구장의7~20시 판정을 대조해 차이0건을 확인했다. 일정 계산 범위 밖이므로 이미 계산한 민감도 배정·열 노출에는 영향이 없으며, 수정된 분석 도구로 상세 일정의 제약·공통 열 노출을 다시 검사한다. 이는 기존 엔진의 단위·변환·입력 버그가 아니다. 기존 관측 스냅샷·PDF·발표 수치를 재생성하지 않는다.

## 실제 실행 및 결과

발표에 권하는 문장:

이어 말하거나 같은 슬라이드에 표시할 조건:

> 경기장 보정 +2.5℃, 유소년의 추정 상단값 판정, 동일 관측소 1곳 공유와 이 가상 대회의 대진·휴식·운영시간·일몰 제약을 적용한 분석 결과입니다.

**관측소 공유 민감도의 한계:** 실제 세 구장의기상/WBGT 관측이 없으므로이 가정의실제변화량은식별할수없다. ±1℃는이번에명시한가상의구장별WBGT편차이며관측 오차·신뢰구간·추가 관측소 자료가 아니다. 비교한 시나리오에서일부연기일수는40/51일(모두−1/+1℃),41/42일(A/C이질편차)이지만실제일수를이범위로추정하지않는다. 위험단계에따라경기단축/쿨링길이도달라지므로수학적단조상하한으로주장하지않는다.

보정0℃ 비교에서미완료46→30일, 중앙값비교에서는46→34일, 두가정결합은46→15일이었다. 이는결론의가정의존성이크다는뜻이며기본정책을낮춰도된다는근거는아니다. 자료1곳·일사결측추정·시간대표값·풍속높이·기압 가정과가상의대진까지포함한조건부시뮬레이션이다. 실제유소년행사개최가능성/안전성으로확대하지않는다.


## 발표 해석과 수용 기준

실제 검사:

- 계산·분석·저장 결과 관련 `python -m pytest tests/test_wbgt_sanity.py tests/test_wbgt_sanity_analysis.py tests/test_wbgt_sensitivity_results.py -q` → **55 passed**,9.52초,건너뛴 검사0개. 저장된558개 상세 일정을 수정된 분석 입력으로 재검증하고 공통 경기의 원래/제안 열 노출을 재계산했다.
- 전체 회귀 `python -m pytest -q` → **278 passed**,25.30초,기존 TestClient 사용 중단 예정 경고1개. 기존223개 검사를 유지하고 신규55개를 추가했다. 테스트 약화/삭제 없음.
- 9개 가정×62일 실제 재풀이558회: **548 OPTIMAL / 10 FEASIBLE / 0 폴백**. FEASIBLE은전부15경기배정이며연기수0건은최선,2차비용최적성은미증명. 각 가정의미완료일은모두최소연기증명됨.
- 수정 후 별도 재컴파일한 소스 출력 대조: 대상6개 최대 차이 모두0.0. 기본 엔진·프론트엔드·정책·관측 입력·기존 재현표·발표 원고의 Git diff0건.

기본46일은 **가상12팀15경기를 같은 날 전부 완료하지 못하는 날짜 수**다. 일부 경기조차 배정할 수 없는 날은3일(8월4~6일)이며 다른43일은 일부 배정이 가능하다. 일반적인 유소년 대회 개최불가일수나 의학적 판단으로 확대할 수 없다.

수원1개 관측소 공유의 실제 영향은 각 구장 관측이 없어 식별할 수 없다. 구장별±1℃는 분석자가 명시한 가상의 WBGT 편차일 뿐 새 관측·관측 오차·신뢰구간이 아니다. 같은 실제 관측을 공유하는 기본 결과와 무엇이 달라질 수 있는지 조건부로 비교하며, 실제 변화량은 별도 측정이 필요하다고 보고한다. 강화된 단계에서 경기시간 단축이 발생하므로 이 표를 수학적 단조 상하한으로 주장하지 않는다.

정책/운영값 불변, 가정별 실제 재풀이, 시간 제한/솔버 상태 정직한 기록, 관측소 공유의 측정 불가 한계 공개, 조건부 발표 문장 작성이라는 수용 기준을 확인한다. 최종 표·테스트·커밋은 `../wbgt-sanity-report.md`에 통합한다.
