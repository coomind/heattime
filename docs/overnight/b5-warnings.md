# B5 동작을 보존하는 경고 정리

2026-10-02. 화면 구성, 계산, 정책, 운영값, 솔버 제한, 안전 문구는 유지했다.

## 변경 요약

- 프론트엔드 빌드에서 React, 차트, 공통 라이브러리, 스냅샷 내보내기 자료를 별도 파일로 분리했다. 경고 임계값을 올리거나 경고를 숨기지 않았다.
- 미리 계산한 PDF·CSV를 `snapshot-exports.json`으로 옮겼다. 승인 결과, 입력 지문, PDF, CSV가 분리 전과 정확히 같음을 비교했다. 생성 스크립트도 같은 두 파일을 저장하도록 수정했고 문법 검사를 통과했다.
- 기존 스냅샷 PDF 테스트는 새 파일 위치와 입력 지문 일치 검사를 추가했다. 기존 검사는 유지했다.

## 실제 테스트 결과

| 검사 | 결과 |
|---|---|
| 전체 Python 테스트 | 104개 통과, 12.18초, TestClient 경고 1개 유지 |
| 프론트엔드 빌드 | 성공, 번들 크기 경고 없음 |
| 반복 브라우저 E2E | 12개 통과, 25.5초 |
| 결과·PDF·CSV 동일성 | 분리 전후 정확히 일치 |
| 스냅샷 생성 스크립트 문법 검사 | 통과; 이 단위에서 자료 재생성은 하지 않음 |

브라우저 검사는 데스크톱·모바일 각각 일반 모드와 스냅샷 모드를 3회씩 실행했다. 스냅샷 검사는 API 요청을 차단하고 브라우저 연결을 끊은 뒤 새로고침하여 재현→히트맵→상세→승인→가상 알림→PDF 및 팀 조회를 확인한다. 분리한 파일도 오프라인 저장 목록에 포함되어 통과했다.

가장 큰 JavaScript 파일은 369.72 kB이다. 이전 메인 파일 647.77 kB와 스냅샷 파일 501.69 kB에서 분리했으며, 다운로드 총량 감소나 네트워크 성능 개선을 입증한 것으로 해석하지 않는다.

PDF SHA256: `8d2aa38b1e855bdacbb9f9b1e687039b846168c6b390d4b0b2aa27d896797151`

CSV UTF-8 SHA256: `822bd887cad986e3eac7477619d175aa28f8635b3447d884125e0abf456f534e`

## 유지한 경고와 사유

설치된 Starlette의 TestClient 코드를 확인했다. `httpx2`가 설치되어 있으면 이를 사용하고, 없으면 기존 `httpx`를 사용하면서 사용 중단 예정 경고를 낸다. 현재 `httpx2`는 없다. 이를 설치하면 테스트 HTTP 통신 라이브러리가 바뀌므로 동작 변경 가능성이 있다. 사용자의 B5 조건에 따라 전환을 건너뛰고 경고를 그대로 유지했다. 테스트를 삭제하거나 경고 필터를 추가하지 않았다.

브라우저 실행의 `NO_COLOR`/`FORCE_COLOR` 충돌 경고도 실행 환경의 표시 설정에서 나온다. 이번 변경 범위에서 환경 설정을 덮어쓰거나 경고를 숨기지 않았다.

## 내가 확인할 항목

- 시연 브라우저에서 새 빌드를 한 번 열고 `시연 자료 저장됨` 표시를 확인한 뒤 연결을 끊어 새로고침한다.
- 스냅샷 PDF의 한글과 기존 의사결정 보조 문구를 확인한다.
- TestClient 경고는 남아 있다. 향후 통신 라이브러리 전환은 별도 동작 검증이 필요한 변경으로 다룬다.
- 번들 분리는 총 자료 크기를 줄였다는 의미가 아니다. 실제 시연 PC에서 최초 저장 시간을 확인한다.
