# A 실제 샘플 확인 · 2026-10-02

`rg --files --hidden --no-ignore data/samples`로 git 제외 파일까지 확인했다.
존재 파일은 README.md 한 개뿐이며 실제 ASOS 수집 결과가 없다.
사용자 조건에 따라 A1~A5 전체를 건너뛴다. 어댑터·실측 일사 지표·관측 날짜별 재현·발표 원고를 갱신하지 않았다.
실제 시연 후보 날짜 상위3일도 없음. 합성 결과를 실제 후보로 대신 제시하지 않는다.
.env를 읽거나 출력하지 않았고 수집 스크립트를 실행하지 않았다.
후속 실제 샘플을 넣으면 지점·일사 누적 구간·단위·시간대를 확인한 뒤 A를 별도 수행해야 한다.
