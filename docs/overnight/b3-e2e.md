# B3 반복 가능한 전체 브라우저 시연

## 변경 요약
npm run test:e2e:repeat: 매번 빌드 후3회 반복. 데스크톱/모바일×일반/스냅샷×3=12개.
테스트 서버는 별도8127포트·실행마다 새SQLite를 사용하고 다른 서버를 재사용하지 않는다.
기존 단언을 유지하면서 실제 제안의하드제약/15경기 배정+연기/공통경기ID/중지구간금지,
중복 승인422·알림 불변 검사를 추가했다. 반복별 화면/PDF/CSV출력명을 분리했다.
README에 반복명령·격리서버와 실제 검증Python/Node버전을 적었다.

## 실제 테스트 결과
npm run test:e2e:repeat: 빌드 성공, **12 passed (26.0s)**.

스냅샷은API차단·완전오프라인새로고침·전체흐름·읽기전용을3번씩 통과.

산출물:data/output/overnight/e2e/ 및스냅샷PDF(모두git제외).

## 수용 기준 / 직접 확인
