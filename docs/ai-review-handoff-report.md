# 추가 경쟁력 점검과 다른 AI 평가 인계 보고

> 2026-10-11 재계산 안내: 이 문서의 수치는 작성 당시 기준입니다. 일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정 이후의 현재 수치는 [재계산 보고](recalc-2026-10-11.md)를 따릅니다.

2026-10-06. 요청에 따라 더 할 일이 없는지 점검하고, 실측 없이 가능한 추가 분석과 다른 AI가 읽을 평가 자료를 정리했다. **추가 점검에서 중요한 결과 품질 한계를 발견했으므로, 수상권 입증이나 개선 완료를 단정하지 않는다.** 다른 AI에 실제로 메시지를 보내거나 외부 파일을 업로드하지 않았다.

## 변경 요약

- 기존16팀·27경기·2일 가상 대진을 모든31개 비중복 관측 구간에 적용하고 같은 제약의 단순4종과 비교했다. 모든 결과·지문·배정·연기·상태·시간을 별도 JSON과 [규모 검증 보고](tournament-scale-report.md)로 남겼다.
- [독립 평가 인계 문서](ai-review-pack.md)에 공식 요강·구현·모든 핵심 수치·가정·한계·다음 개선·읽을 파일·평가 요청문을 모았다.
- 제출 제안서/근거/공모전 비교/심사 요약/QA에16팀의 불리한 결과와 일반화 한계를 추가했다. 기존12팀 우위와1.39% 증가도 그대로 둔다.7분 본 발표/3분 시연 구성은 유지한다.
- 로컬 리뷰ZIP 생성 도구를 추가했다. 추적된 코드·문서·가상 분석·커밋된 인증값 없는 정규화 ASOS 입력만 포함한다. .env·원 API 수집 응답·런타임 DB/검증 기록·미추적 파일을 열지 않고 제외한다. 외부 전송은 하지 않는다.
- README의 재현 설명을 정정했다. 원 data/samples/ 파일이 필요한 것이 아니라 커밋된 data/observations/ 정규화 자료로 분석한다. 키/수집 없이 재현 가능하다.

기간·대진·교집합이 다르므로 두 열을 합쳐 전체 효과를 주장하지 않는다. 추가 결과는 전체 배정이2건 적으며 이 점을 열 노출 개선율로 감추지 않는다.7월9~10일은 FEASIBLE16 / 단순27배정,8월16~17일은 폴백26 / 단순27배정이었다. 두 단순 대안도 같은 하드 제약·권고·점수를 통과했다. 이 엔진 연기를 전부 날씨 때문에 불가피했다고 설명할 수 없다.

추가 규모 분석은348.478초. 제품 최적화 호출 준비/검사 포함 중앙10.637초·최대11.2187초다. 솔버 탐색10초를 유지했고 전체 응답10초 보장을 주장하지 않는다. 같은 결과를 더 좋게 만들려고 재풀이하지 않았다.

## 판단과 남은 작업

지금 가장 구체적인 코드 개선 후보는 FEASIBLE/폴백과 동일 제약이 검증된 단순 대안을 비교해 배정 수 우선·동수 비용 우선으로 결과를 선택하는 절차다. 현재는 기존 엔진 불변 범위 때문에 구현을 바꾸지 않았으며 다음 검토의 구체적 사례/회귀 검사 대상으로 남겼다. 다른 AI가 이 문제의 원인·수정 범위·목적/상태/승인 기록에 미치는 영향을 코드로 검토할 수 있도록 자료를 포함한다. 실제 구장 실측이 이 문제를 발견하거나 검토하는 데 필요하지 않았다.

또한 기본10초 최신 관측 안정성,7분 설명/시연 영상/외부 확인 자료, 고객 가치 설명은 남아 있다. 실제 배포·로그인·영상/PPTX 제작·발송은 기존 작업 경계로 하지 않았다. 현장 정확도·운영자 효용·구매 수요는 현재 자료로 입증되지 않는다. 이를 성공 실적으로 바꾸는 기능을 추가하지 않는다.

## 실제 테스트·수용 기준

## 내가 확인할 항목

1. 다른 AI에는 우위뿐 아니라16팀의두 열세 사례와 FEASIBLE/폴백도 전달한다. 개발자의 긍정 평가에 맞추도록 유도하지 않는다.
2. [평가 인계 문서](ai-review-pack.md)만 첨부해 요약 평가를 받거나, 로컬 `data/output/ai-review/HeatTime-AI-review.zip`을 첨부해 코드/원자료 검토를 요청한다. 경로만 적으면 원격 AI는 파일을 읽을 수 없다. 대화에 키를 붙여넣지 않는다.
3. 평가자가 실제로 읽은 파일/실행 여부와 모르는 부분을 구분했는지 확인한다. 테스트 수로 고객 가치·현장 안전성을 입증했다는 답은 받아들이지 않는다.
4. 다음 엔진 수정은 두 사례 재현→같은 후보/제약/목적 우선순위→최적성 상태/승인 근거→전체 회귀 검증 순서로 판단한다. 실측을 구하는 조건으로 되돌리지 않는다.
5.7분 발표와3분 시연은 사용자 리허설로 확인하고 미촬영/미배포/미접수 상태를 완료라고 쓰지 않는다.
