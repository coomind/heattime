# 제출 준비 상태와 직접 확인 목록

2026-10-05. [공모요강 비교](competition-fit.md)의 공식 출처를 접수 직전에 다시 확인한다.

| 항목 | 현재 상태 | 사용자가 확인할 것 |
|---|---|---|
| 소개·제안 문구 | [원고 작성](proposal.md) | 이름·신청 정보·최종 제출 형식에 맞춰 정리 |
| 7분 구성 | [원고](../presentation/slides.md)·글자 수 검산 | 실제 발화·클릭으로420초, 시연180초를 소리 내어 확인 |
| 시연 증빙 | 로컬 관측 스냅샷과 자동 테스트 | [캡처 순서](../presentation/capture-list.md)로 영상 촬영, 글자·음량 확인 |
| 최종 발표 파일 | 만들지 않음(사용자 지시) | 필요한 발표 형식·파일 크기는 실제 접수 화면에서 확인 |
| 외부 서비스 주소 | 배포하지 않음 | 필요 시 사용자 권한으로 준비하고 로그인 없는 새 창·휴대폰에서 확인 |
| 고객 증거 | 인터뷰·지불 의사 미검증 | [계획](validation-plan.md)으로 실제 운영자에게 확인; 결과를 과장하지 않기 |
| 현장 정확도 | 국내 구장·전문가 자문 미완료 | +2.5℃·상단값·관측소 공유 가정, 현장 대조 미수행을 유지 |
| 대표 시연 | 7월10일의 관측 입력 가상 대회 | 새 자동 제안 요약의15배정/0연기/10재배정/29.36%와 승인 전 표시 확인 |
| 전체기간 결론 | 조건부46일·0배정3일 | 시연 수치와 민감도 수치를 다른 화면에 표시 |
| 출처·라이선스 | 기존 고지 유지 | [출처](../presentation/sources.md) 링크와 공개 구현·글꼴 고지 포함 |
| 참가·일정 | 공개 요강 확인 | 신청자격·접수 완료·필수 참석 여부와 공지 변경 확인 |

서비스 링크·사진·활용 영상은 공개 요강에서 기술·제품 자료의 예시로 제시된다. 세 종류를 모두 필수 서류라고 단정하지 않는다. 미제공 주소나 미촬영 영상을 준비 완료로 표시하지 않는다. 수상 경쟁력을 높이기 위한 자체 확인 목록이며 공식 배점표가 아니다.
