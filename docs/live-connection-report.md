2026-10-05 KST. 사용자 최신 지시 “실제 연결 검증”에 따라 앱 런타임 키 로더와 실제 AWS 조회를 실행했다. 프로젝트 .env 내용과 키를 직접 열람하거나 출력하지 않았다. 기존 ASOS 수집 스크립트는 실행하지 않았다. 실제 배포·로그인·메시지 발송 없음.

## 결론

**AWS 수원 119의 실제 인증 조회·공식 응답 계약·기존 엔진 계산은 확인했으나, 앱 기본 10초 호출의 안정성은 이번 검증에서 통과하지 못했다.** 진단용 30초 제한에서 두 번 성공했고 기본 10초 실행 네 번은 모두 TimeoutError였다. 성공 소요시간은 2.255초와 0.740초로 10초 미만이었으므로, 이 표본으로 타임아웃 길이만을 원인이라고 단정하거나 “30초로 바꾸면 해결”이라고 주장하지 않는다. 기본값을 바꾸거나 실패를 제외해 성공률을 만들지 않았다.

공개 홈페이지 접속 200(0.062초), 키 없는 해당 API의 401(0.093초), DNS 확인이 성공했다. 전체 인터넷 차단이나 키 오류로 단정할 수 없다. 인증 조회가 실제 자료를 반환했으므로 해당 지점/서비스 조회 권한은 확인했으며 다른 API 권한까지 확인한 것은 아니다. 서버 처리·경로 지연의 구체 원인은 미확인이다. 짧은 6회 관측을 장기 장애율/SLA로 일반화하지 않는다.

30초 옵션은 **검증 스크립트 실행에만 적용**하며 앱의 10초, 솔버의 10초, 대회 운영값을 바꾸지 않았다. 로컬 앱 HTTP 200과 기상청 HTTP 200을 구분했다. 앱이 status:error로 반환한 로컬 200은 관측 성공이 아니다.

## 응답·입력 검증

두 성공은 공식 [AWS 1.1 문서 계약](kma/aws-minute-spec.md)과 동일한 18필드 헤더·18열·1행이었다. TM/YYMMDDHHMI KST, TA ℃, HM %, WS10 m/s(10분 평균), PA/PS hPa, RN-60m mm에 추측한 변환을 추가하지 않았다. 0mm 강수도 유효값으로 확인했다.

최종 성공: **2026-10-05 23:35 KST·수원 119**, 가져온 시각 23:38:09.608632 KST. 기온 11.9℃, 습도 58.3%, WS10 0.2m/s, 현지기압 1011.3hPa, 해면기압 1016.1hPa, 60분 강수 0mm. 관측 시각부터 수집까지 약 **189.6초** 차이였다. 전송 시간과 관측 생산/제공 지연을 섞지 않는다. 분 자료를 지연 없는 현장 실측으로 소개할 수 없다.

일사·운량·WBGT는 이 응답에 없다. 등록된 가상 구장 3곳에 입력을 공유하고 기존 일사 추정·높이 가정·스크리닝 기압 1013.25hPa·+2.5℃ 구장 보정·유소년 상단 판정을 유지했다. 최종 자료의 세 구장 중앙 WBGT는 10.401℃, 범위 8.901~11.901℃이며 Liljegren 계산 경로였다. 현장 WBGT 검증 수치가 아니다. 야간 두 시점으로 주간 일사·폭염 정확도나 구장 공간 대표성을 검증하지 못한다. 기존 7월10일 시연·62일 재현 수치를 갱신하지 않았다.

안전한 [성공 기록](kma/live-connection-verification.json), 숫자만 재구성한 `tests/fixtures/aws-119-20261005-2335.txt`를 보존했다. 원문 전체·주석·URL·헤더·키를 저장하지 않는다. 샘플은 현재 관측을 자동 갱신하는 자료가 아니라 이 검증 시점의 고정 회귀 자료다.

## 코드 및 검사 보완

- `scripts/verify_live_connection.py`: 실제 앱 엔드포인트를 한 번 검증하고 허용 필드만 기록. 원문/알 수 없는 헤더를 노출하지 않는 구조 진단, 기본 실행과 진단 제한 표시, 로컬/기상청 상태 구분, 숫자 샘플 재구성. 단위/E2E 검사에서는 실호출하지 않는다.
- `aws_live.py`: TimeoutError 고정 안내, 요청 종료 후 실제 남은 호출 간격 계산. 이전에는 실패 직후 0초로 표시되고 다음 요청에서 대기가 나타났으므로 이를 수정했다. 호출 간격 자체는 유지한다.
- `LiveWeather.jsx`: 실패를 키 오류로 단정하지 않고 관측 시각 확인 및 관측 시연 스냅샷으로 이어가는 링크 제공.
- Python 신규 9개: 안전한 기록·알 수 없는 구조/헤더·실제 샘플 단위·상태 구분·실패 후 50초 남은 간격. 브라우저 신규 데스크톱/모바일 2개: 시간 초과·간격·스냅샷 전환 이후 API 요청 0.

실제 테스트: 집중 Python **42개 통과**, 3.59초; 전체 Python **598개 통과**, 132.35초; 화면 단위 **21개 통과**, 227.36ms; 최신 빌드 통과, 3.29초. 전체 데스크톱/모바일 브라우저 **90개 통과**, 약 3.2분(30개×3회). 기존 Python TestClient 경고 1건은 유지했다. 기존 검사 삭제/약화, 정책·엔진·솔버·운영값·명세·원본 스냅샷 변경 없음.
