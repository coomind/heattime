# 기능 3: CSV 저장 전 미리보기

> 이전 기준 기록입니다(2026-10-21 이전: 유소년 범위 상단 판정). 현재 수치와 기준은 [2026-10-21 재계산](recalc-2026-10-21.md)을 보세요. 2026-10-11 재계산(일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정) 기록은 [2026-10-11 재계산](recalc-2026-10-11.md)에 있습니다.

2026-10-05. CSV 파일 선택은 조회·검증만 수행한다. 신규/수정/동일 경기, 팀·구장·일정·선행 ID와 행별 오류를 표시하고 별도 확인 저장을 제공한다. 취소는 저장하지 않는다. 선택 대회의 기존 경기 한 행을 포함한 양식도 제공한다.

저장 때 동일 검사를 다시 수행하고 미리보기 당시 등록 자료 지문을 대조한다. 자료가 바뀌면 409로 거절하고 재확인을 요구한다. 기존 경기 가져오기 API의 응답 및 필수 제약은 유지한다. 다른 대회의 ID 충돌, 시각·날짜, 팀·구장 참조, 선행 그래프, CSV 구조 오류는 저장 전에 검사한다. 양식의 수식 위험 문자열은 기존 내보내기 규칙으로 처리한다.

변경 파일: backend/csv_import.py, backend/app.py, CsvImport.jsx, App.jsx, styles.css, tests/test_csv_preview.py, frontend/e2e/csv-preview.spec.js.

새 E2E의 최초 탐색은 데스크톱 메뉴의 순번을 고려하지 않았고 다음 탐색은 대회 선택 이름이 불명확해 실패했다. 메뉴는 기존 이름에 맞게 탐색하고 실제 대회 선택에 명시적 접근성 이름을 추가했다. 저장 전/후 API 내용 검사 등 행동 단언은 유지했다. 테스트마다 대회·경기를 독립 등록해 공유된 예시를 변경하지 않는다. 단위 테스트 실행 명령의 첫 시도에는 존재하지 않는 npm test를 사용했고, 문서의 npm run test:unit으로 21개를 실제 재실행했다.

## 사용자가 직접 확인할 항목

일반 재현 모드에서 대회를 고른 뒤 설정의 CSV 저장 전 미리보기를 연다. 양식을 내려받아 확인하고 파일을 고른 뒤 취소하면 기존 경기가 유지되는지 확인한다. 행 오류를 고치고 다시 확인한 뒤 저장한다. 자료 변경으로 409가 나오면 CSV 다시 확인을 누른다. 스냅샷에서는 가져오기가 제한된다. 미리보기는 배정 가능성을 계산하는 솔버가 아니므로 저장 후 새 재현에서 운영 제약을 확인한다.
