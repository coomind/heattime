# 실제 연결 후 공모전 경쟁력 재검증

2026-10-05 KST. 공식 공모요강·기존 서비스의 공식 설명·현재 저장소·실행 결과를 대조했다. 공개 배점과 경쟁 참가작 정보가 없으므로 임의 채점·순위·수상 확률은 만들지 않는다. 아래 항목은 자체 검증 관점이다.

## 판단

**출품 적합성과 기술 시연의 근거는 충분히 구체적이다. 수상권에 있다고 검증할 근거는 아직 부족하다.** 세 기능으로 판단 근거의 확인과 입력 검증이 보강됐고, 실제 AWS 조회 권한·응답·계산도 확인했다. 그러나 최신 기본 호출의 안정성, 현장 WBGT 정확도, 운영자 효용·구매 의사는 이번 작업으로 통과한 항목이 아니다. 기능 수나 자동 테스트 수를 고객 검증의 대체 근거로 쓰지 않는다.

현재 시제품의 방어 가능한 주장은 “폭염 판정과 대진·휴식·일몰 제약을 함께 적용한 일정 대안, 연기 사유와 운영자 판단 기록을 확인할 수 있는 축구대회 의사결정 보조”다. API 연결 자체나 자동 대진만을 신규성으로 내세우지 않는다. 국내 최초·경쟁사보다 정확·사고 예방 보장·실제 대회를 살린 성과는 검증하지 않았다.

## 실제 연결이 증명한 것과 못한 것

[실제 연결 보고](live-connection-report.md) 및 [성공 기록](kma/live-connection-verification.json). 2026-10-05 야간 수원 119의 두 관측을 수신했고 최종 자료는 기온 11.9℃·습도 58.3%·WS10 0.2m/s였다. 자료의 관측 시각은 가져온 시각보다 약 3분 이전이었다. 이는 인증·파싱·현재 관측 시각의 계산 확인이지 주간 폭염 성능 검증이 아니다.

일사·운량·WBGT 실측은 이 서비스에 없고 기존 추정/가정을 사용한다. 같은 관측소 1곳을 가상 구장들에 공유한다. 현재 관측을 향후 경기 시각의 예보처럼 시간 전체에 복제하지 않는다. 최신 관측 패널은 재현·승인 결과를 갱신하지 않으며 미래 예보 연결은 별도 미완료다. 기본 10초 실패를 진단용 30초 성공으로 덮거나 장기 가용성을 주장하지 않는다.

**발표에서 사용 가능한 사실:** “과거 관측 재현과 오프라인 시연을 지원하고, API허브의 실제 AWS 자료 수신과 입력 계약을 확인했습니다. 최신 조회는 지연·시간 초과가 있어 시연은 고정 관측 스냅샷으로 준비했습니다.”

“실시간 현장 WBGT를 측정한다”, “실제 대회에 적용 검증됐다”, “업무시간을 절감했다”, “실시간 운영 안정성이 확보됐다”는 문장은 아직 사용할 수 없다. 기존 62일 조건부 결론·가정·7월10일 수치·민감도 구분은 유지한다.

## 실행 검사 및 변경

실제 연결·오류 보완 커밋 **73ca982**. 전체 Python **598개**, 화면 단위 **21개**, 전체 브라우저 3회 반복 **90개** 통과. 이것은 코드/가상 흐름 검증이며 사업성·현장 정확도·수상권 검증 통과를 의미하지 않는다. 원고의 새 구현 사실·연결 한계를 제안서/증거표/한 장 요약/준비 상태에 반영하고 기존 7분 본 발표는 변경하지 않는다. 문서 변경 뒤 기존 발표 **16개**, 제출 **10개**, 경쟁력 근거 **8개** 정합성 검사가 전부 통과했고 관련 문서의 로컬 참조 **53개**를 확인했다. 기존 전체기간·동일 제약 비교 회귀 **69개**도 실제 재실행해 48.89초에 통과했다. 처음 검사 결과를 모으는 보조 실행에서는 Windows 출력 인코딩 불일치가 있었고 UTF-8 실행으로 결과를 다시 수집했다. 검사 코드·기준은 변경하지 않았다.

## 사용자가 직접 확인할 항목

1. 관측 스냅샷에서 제안/승인 근거, 입력 단위/이력, 연기 사유, PDF를 열고 본인이 설명할 수 있는지 리허설한다.
2. 실제 운영자·구매자가 최근 변경 사례를 갖는지 확인하고 문제 없다는 응답도 기록한다. 계획을 고객 실적으로 소개하지 않는다.
3. 전문가와 측정 조건을 합의하기 전 현재 추정 범위를 검증된 오차 범위로 소개하지 않는다.
4. 최신 연결의 시간 초과·약 3분 지연 사례를 숨기지 않는다. 실제 최신 자료는 별도 보조 장면, 고정 7월10일 재현은 본 시연으로 구분한다.
5. 접수 직전 요강·파일 형식·필수 참석을 확인하고 실제 영상/발표 자료/외부 증빙을 준비한다. 127.0.0.1 주소는 심사위원용 공개 서비스 주소가 아니다.

현재는 “기술과 설명 가능한 시연이 강화된 출품 시제품”으로 평가한다. 수상권 판단의 가장 큰 공백은 운영자·현장 실증과 제출 증빙이며, 이 공백을 기능 추가만으로 해소했다고 결론내리지 않는다.
