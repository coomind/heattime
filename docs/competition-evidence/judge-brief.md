# 심사 자료 검토용 한 장 요약

HeatTime은 생활체육·유소년 축구대회의 폭염 판단을 **대진 제약을 지키는 일정 대안·연기 사유·운영자 승인 기록**으로 연결하는 의사결정 보조 웹 시제품이다. 명세의 안전·시설 관리 기술을 중심으로 대회 운영·관리 기술과 연결한다. 이 문서는 자체 설명 자료이며 공식 심사 항목·배점이 아니다.

| 확인할 질문 | 실제 화면의 증거 |
|---|---|
| 어떤 결정을 돕는가? | 재편성 비교의 배정/연기 요약, 경기별 원래→제안 킥오프·구장·권고 종료·연기 사유 |
| 조합 탐색을 할 가치가 있는가? | 재현 모드의62일 전체 결과와 동일 하드 제약의 탐욕 비교. 유리한 결과와 비용 모두 공개 |
| 누가 결정하고 무엇을 보존하는가? | 승인 전 제안 → 운영자 판단 → 모의 팀 안내 → 입력·범위·정책·사유 PDF |

README대로 실행한 뒤 `http://127.0.0.1:8000/#snapshot-observed`를 연다. 최초 방문은 서버가 필요하고 저장·새로고침 후에는 오프라인에서도 동작한다. 외부 배포 주소·영상은 아직 제공하지 않았다.

## 별도 알고리즘 비교

수원119 관측 입력의62개 가상 대회에서 고정 CP-SAT 제안은 기존 탐욕 폴백보다 배정 합계가56건 많았다(506→562건).15경기 전부 배정일은0→16일이었다. 동시에 공통 경기 열 노출 점수 합계는1.39% 높았다. 연기 수를 먼저 줄이는 우선순위의 비용이며 건강 효과가 아니다. [전체 원본과 해석](method-comparison.md).

가정: 경기장 보정 +2.5℃, 유소년 추정 상단값 판정, 동일 관측소 1곳 공유, 이 가상 대회의 대진·휴식·운영시간·일몰 제약. 같은15경기의 날짜별 반복 배정 건수이며 실제 대회에서 살린 경기 수가 아니다. 탐욕의 미배정은 전역 불가능 증명이 아니다. 사람·경쟁 제품과 비교하지 않았다.

기존7월10일의 원래→제안 점수와 다른 교집합이다.7분 본 발표의 시연·62일 조건부 분석·민감도 화면은 유지하며 알고리즘 비교는 질의응답 부록으로 보여준다.

## 후속 구현과 실제 연결 확인

제안/승인 일정의 운영 제약, 기상 단위·일사 변환·보정 이력, CSV 저장 전 미리보기를 확인할 수 있다. [구현 보고](../feature-implementation-report.md). 실제 AWS 자료 수신·응답·기존 계산은 확인했으나 기본 10초 호출은 네 차례 시간 초과여서 최신 조회의 운영 안정성은 미검증이다. [실제 기록](../live-connection-report.md). 최신 기상 입력은 현장 WBGT 측정이나 미래 예보가 아니며 기존 7월10일 시연 수치를 바꾸지 않는다.

[경쟁력 재검증](../competition-validation-report.md)은 기술 시제품의 구체성은 강화됐지만 운영자 효용·국내 구장 정확도·구매 의사와 제출 영상/외부 증빙이 아직 부족하다고 평가한다. 공식 채점이나 수상권 판정이 아니다.
