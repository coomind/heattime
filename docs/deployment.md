# 시연 배포 절차 (설정 준비 완료, 실제 배포 미실행)

사용자 지시에 따라 계정 로그인·서비스 생성·실제 배포는 하지 않았다. 현재 외부 서비스 링크는 없다.
Python API가 빌드된 React 화면까지 제공하는 단일 서비스이며 API 키 없이 합성 기상으로 동작한다.
실제 기상 API 및 문자/카카오 연동은 연결되지 않았다.

## 로컬 재현

README 설치 후 `python -m backend.run --host 127.0.0.1 --port 8000`을 프로젝트 가상환경에서 실행한다.
http://127.0.0.1:8000 에서 재현 실행 → 경기 상세 → 재편성 → 사유 작성·승인 → 알림 → PDF까지 확인한다.
정적 화면을 사용하려면 먼저 frontend에서 `npm ci`, `npm run build`를 실행한다.
서버 재시작 후 기존 세션 ID의 기록이 SQLite에 남는 것은 자동 테스트로 확인했다.

## Docker

프로젝트 루트에서 아래 실행. 이번 환경에는 Docker 실행 파일이 없어서 이미지 빌드는 검증하지 못했다.
동일 Python 서버와 정적 빌드는 로컬에서 검증했다. 클라우드 최초 빌드에서 Linux 의존성 설치도 확인해야 한다.

```text
docker build -t heattime-demo .
docker run --rm -p 10000:10000 heattime-demo
```

http://127.0.0.1:10000 확인. 컨테이너 삭제시 기록도 삭제된다. 보존하려면 사용자 환경의 data 디렉터리를
/app/data에 연결한다. .dockerignore로 .env·샘플·로컬 DB·출력물을 이미지에서 제외한다.
mock 기상은 코드에서 생성하므로 별도 키/실제 샘플 파일이 필요 없다.

## Render 무료 시연 서비스 (사용자가 계정으로 수행)

1. 저장소를 본인 Git 호스팅에 올린다. .env·실제 응답 샘플·개인정보·로컬 DB는 포함하지 않는다.
2. Render에서 New → Blueprint로 저장소를 연결하고 render.yaml을 검토한다.
3. Docker / free / health check `/api/health` / port10000을 확인한다. 키 입력은 필요 없다.
4. 배포 로그에서 Python 의존성·프론트 빌드 및 health check 성공을 확인한다.
5. 제공된 HTTPS 주소를 시크릿 창과 휴대폰에서 로그인 없이 연다.
6. 재현 전체 흐름과 PDF 한글, 읽기 전용 팀 일정 링크를 검사한다.
7. 그 주소와 직접 촬영한 대체 영상을 접수 자료에 기입한다.

설정 형식은 [Render Blueprint 공식 문서](https://render.com/docs/blueprint-spec)를 기준으로 준비했다.
무료 서비스는 유휴시 중단될 수 있고 저장소가 임시이므로 재기동·재배포시 운영 기록이 사라질 수 있다.
제출 전 PDF/CSV/JSON을 다운로드하고 첫 접속 대기와 재현 시연을 점검한다.
무료 서비스에 영구 디스크를 지원하지 않는 제약은 [Render 무료 서비스 문서](https://render.com/docs/free)를 확인한다.
실제 운영용 자료 보관·접근 제어는 별도 설계가 필요하며 현재는 가상 시연용이다.

## 배포 전 확인 항목

- 현재 외부 접속 검증은 미실행이다. 로컬 테스트 성공을 외부 배포 성공으로 표시하지 않는다.
- 무료 인스턴스의 메모리·콜드 스타트·10초 솔버 요청 응답을 실제 서비스에서 확인한다.
- 공개 데모는 로그인 없는 공유 상태다. 가상 입력만 사용한다.
- 실제 데이터 어댑터는 data/samples의 비밀값 제거 응답과 공식 명세 확인 후 구현한다.
- 의존성의 라이선스 원문과 NanumGothic OFL을 배포물에 유지한다.
