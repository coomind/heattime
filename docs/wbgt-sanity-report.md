## 결론

8월 6일 16시의 **38.062℃는 관측 WBGT가 아니다.** 관측 입력 기반 Liljegren 추정 35.561535℃에 명세의 경기장 보정 +2.5℃를 더한 중앙값이다. 최종 범위는 36.562~39.562℃이며 유소년 판정에는 39.562℃를 쓴다. 해당 시각의 2m 환산 풍속은 0.217434m/s, 자연습구 30.760340℃, 흑구 52.346489℃였다. 약한 바람에서의 복사 성분과 경기장 보정이 높은 값을 설명한다.

확인한 단위·일사 변환·입력 순서·풍속 보정에는 명백한 버그가 발견되지 않았다. 설치된 lwbgt 1.0.1과 수정하지 않은 같은 버전의 공개 C 소스를 별도 컴파일하여 여섯 대상의 5개 출력을 비교했고 차이는 모두 0.0이었다. 이는 구현 일치 검증이며 실제 현장 WBGT 정확도, 38℃의 발생 빈도, 건강 영향이나 안전성을 검증한 결과가 아니다. **모델·입력 가정의 영향은 남아 있다.**

정책·운영값·안전 문구·기존 테스트·엔진을 바꾸지 않았다. 버그 수정 조건에 해당하지 않아 기존 62일 일정·시연 후보 순위·관측 스냅샷·PDF·발표 원고 수치를 재생성하지 않았다. 62일의 4,464개 구장×시간 WBGT를 새로 계산하여 이전 입력 해시와 날짜별 최고값을 대조했다. 모두 주 엔진을 사용했고 폴백은 0개였다.

## 독립 근사 비교의 해석

Stull의 통풍습구 경험식을 별도 구현하고, 그늘에서흑구≈기온·자연습구≈통풍습구라고 단순화한 `0.7Tw근사+0.3Ta`를 비교용으로 사용했다. 저자 원문의20℃·50%→13.7℃ 예제와 일치했다. 식은℃·%·라디안을 사용한 해수면 근사다. 본 대상들은공통으로그 조건의기압 가정을 사용하지만, 통풍습구와 자연습구는 동일한 물리량이 아니다. 이 비교를 야외 WBGT의 정답이나 엔진 대체로 사용하지 않았다.

비교식(저자 식4.19): `Tw = Ta×atan(0.151977×sqrt(RH+8.313659)) + atan(Ta+RH) − atan(RH−1.676331) + 0.00391838×RH^1.5×atan(0.023101×RH) − 4.686035`. RH는47%이면47을 넣는다. 기존 폴백 함수의 일사 보정 항을 가져오지 않고 이 식을 독립 계산했다.

대상6개에서최종 중앙값−그늘 근사 차이는약6.389~11.549℃. 이를 **0.7(Tnw−Tpsy)+0.7(Tpsy−Tw근사)+0.2(Tg−Ta)+2.5**로 나눴다. 보정 전 차이의 주성분은자연습구 복사1.609~4.908℃와흑구2.321~4.321℃이며,습구식 차이는−0.525~−0.041℃로오히려차이를 줄인다. 여기에경기장+2.5℃를 더한다. 일사를0으로한같은엔진 비교는−4.063~−9.329℃이며복사 민감성을 보여준다. 그늘 실측값이나복사 효과의정확도 검증은 아니다.

**관측소 공유 민감도의 한계:** 실제 세 구장의기상/WBGT 관측이 없으므로이 가정의실제변화량은식별할수없다. ±1℃는이번에명시한가상의구장별WBGT편차이며관측 오차·신뢰구간·추가 관측소 자료가 아니다. 비교한 시나리오에서일부연기일수는40/51일(모두−1/+1℃),41/42일(A/C이질편차)이지만실제일수를이범위로추정하지않는다. 위험단계에따라경기단축/쿨링길이도달라지므로수학적단조상하한으로주장하지않는다.

보정0℃ 비교에서미완료46→30일, 중앙값비교에서는46→34일, 두가정결합은46→15일이었다. 이는결론의가정의존성이크다는뜻이며기본정책을낮춰도된다는근거는아니다. 자료1곳·일사결측추정·시간대표값·풍속높이·기압 가정과가상의대진까지포함한조건부시뮬레이션이다. 실제유소년행사개최가능성/안전성으로확대하지않는다.
