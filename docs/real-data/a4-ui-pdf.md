# A4 관측 출처 화면·PDF

- 재현 모드에서 합성/기상청 관측 자료를 선택. 관측 기간과 추천일을 안내하고 실제 샘플 사용 시 **기상청 관측 자료(수원119·날짜)**와 가상 대회·팀·구장을 구분한다. 서버와 읽기 전용 팀 화면에도 출처를 보존한다.
- PDF/CSV/판단 고정 입력에 출처·원본 해시·시간평균 단위·일사 결측을 보존. 관측 PDF의 오래된 “비교 일사량은 합성” 문구만 사실에 맞게 교체. 정책·보정·안전 고지 유지.
- 실제 테스트: 전체 **223 passed**, 18.66초·기존 TestClient 경고1건. 일반 관측/관측 스냅샷/기존 합성/캐시 교체 E2E **30 passed**(데스크톱·모바일, 각각3회, 1.3분). 관측 일반 읽기 전용 링크의 출처까지 검사.
- 첫 신규 PDF 테스트는 경기 근거 구간에 결측이 있다고 잘못 가정해 실패했다. 실제7월10일 경기 구간에는 관측 일사가 모두 존재함을 확인했고, 일 전체9시간 결측 요약 검사와 실제 야간 결측 구간을 사용하는 별도 PDF 검사로 수정·강화했다. 기존 테스트 수정/삭제 없음.
- 실제 관측 스냅샷 PDF26페이지 전체 렌더링·접촉시트 검사, 첫·경기 페이지 확대 검사. 텍스트 경계 위반0, 한글 글꼴·하단 **본 자료는 의사결정 보조용 추정값** 확인. 근거 블록을 묶어 산정 방법/해시만 다음 페이지에 고립되지 않게 했다.
- 화면 데스크톱/모바일 이미지 확인: 관측 날짜·스냅샷·가상 라벨 읽힘, 가로 화면 넘침 없음. 타임라인은 내부 스크롤.
- Docker 설정에 인증 정보를 제거한 관측 파일·지점 표·추천 메타데이터만 포함. .env·원본 샘플·출력 파일 제외 규칙 유지. Docker 실행/실제 배포/로그인 없음.
- 수용 기준: 관측 출처 정확 표기·합성 혼동 없음·PDF 전 페이지 고지·과거 입력 변경 후 출처 고정·전체 흐름 통과.
- 직접 확인: `기상 자료 → 기상청 관측 자료 · 수원119`,7월10일 재현·상세·승인·팀 화면과 PDF 첫/경기 페이지. 구장 현장 측정과 기상청 관측 입력을 구분해서 소개할 것.
