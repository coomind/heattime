# A2 실제 일사 비교

- 실제 관측 927쌍, 결측561시간 제외(빈 값과0 구분). 같은 이전1시간 구간으로 기존 일사 추정식을 1분 중점 적분. 30초 적분과 비교한 오차0.05W/m² 미만 테스트 통과. 감쇠계수·비·고도 가정은 그대로 유지.
- MAE **62.67W/m²**, 편향(추정−관측) **+6.74W/m²**, RMSE93.96W/m². 양의 관측881시간만 MAE65.91W/m². 최대 절대 오차460.07W/m²로 일부 시간 오차가 크다. 평균 편향이 작다고 개별 시간이나 WBGT가 정확하다는 결론을 내리지 않는다.
- `solar/solar-metrics.json`, `solar-pairs.json`, `solar-comparison.png` 갱신. 그래프의 결측은 빈 구간이며0으로 채우지 않는다. 시계열·산점도 범례와 수치를 이미지로 확인.
- 기존 가상 구장 좌표를 계산에 유지. 정확한 관측소 좌표를 추측하지 않았고, 정시 운량/강우를 이전1시간 동안 일정하다고 두는 한계가 있다. 결과를 개선하기 위한 계수 조정 없음.
- 실제 테스트: 전체 **153 passed**, 15.23초·기존 경고1건. 결측 그래프와 추가 지표 수정 후 관련 테스트3개 재실행 통과(2.46초).
- 수용 기준: 실제 샘플·동일 시간 구간·결측 제외 개수·MAE/편향/그래프·부진한 시간 오차 공개 통과. 합성 비교 산출물은 과거 기록으로 보존하며 이번 실제 결과와 구분.
- 직접 확인: 비교 그래프의 큰 편차, 561시간 제외, 시간평균과 정시 대표값의 차이, 현장 WBGT 검증은 별도라는 한계.
