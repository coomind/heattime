# A1 실제 ASOS 어댑터

> 이전 기준 기록입니다(2026-10-21 이전: 유소년 범위 상단 판정). 현재 수치와 기준은 [2026-10-21 재계산](../recalc-2026-10-21.md)을 보세요. 2026-10-11 재계산(일사 구간 정렬·판정값 0.1℃ 반올림·동점 처리 고정) 기록은 [2026-10-11 재계산](../recalc-2026-10-11.md)에 있습니다.

- 수원119, 2026-07-01~08-31, 62일·1,488시간을 로컬 어댑터에 연결. 원본은 수정하지 않고 공개 기상 필드만 정규화해 `data/observations/`에 보존한다.
- `tm`은 KST 정시. `icsr`는 MJ/m²로 표시된 이전 한 시간 에너지이며 하루 누적값이 아니다. `MJ/m² × 1,000,000 / 3,600`으로 시간평균 W/m² 변환. 근거와 시간 대표값의 한계는 `docs/kma/asos-observation-evidence.md`에 기록.
- 일사 927시간 유효(0 포함), 561시간 결측. 결측을 관측0으로 대체하지 않는다. 운량2시간 결측은 기존0.7 가정으로 기록. 기온·습도·풍속 결측/오류 플래그는 재현을 거부한다.
- 전운량/10은 실제 운량 비율로 사용하며 예보 SKY 코드를 만들어내지 않는다. 정책·운영값·일사 감쇠 공식·안전 문구는 유지.
- 실제 실행: `.venv\Scripts\python.exe -m pytest -q` → **150 passed**, 13.10초. 기존 TestClient 사용 중단 예정 경고1건 유지. 최초 신규 테스트의 지점 표 단언에 공식표의 소속 기관 필드를 빠뜨려 실패했고, 실제 표 전체를 정확히 검사하도록 수정 후 통과.
- 수용 기준: 필드·단위·시간·해시·결측·QC·저장 복원·무네트워크/무키 읽기 검사 통과. 수집 스크립트 실행 없음.
- 직접 확인: 제공한 원본 해시, 수원119 지점, 시간평균의 근거와 현장·구장 기상 차이. 전운량 정시값은 이전 한 시간 구름 변화 전체를 나타내지 않는다.
